## 流程结构

```
S1 理解输入
  ├─ A1 需求信号解析（5类信号）
  ├─ F1 事实推断分离（[FACT]/[STATED]/[INFERRED]标注）
  ├─ F2 根本需求追溯（裸需求提炼）
  ├─ F3 关键洞见提炼（4条高密度结论）
  ├─ X1 客户端类型分级（判定为"品牌参考型"）
  ├─ A2 信息充足度评估（缺口记录）
  ├─ A3 交付边界锁定（本轮范围）
  └─ 一主两辅 S1 锚定（空间/驱动力/边界初始识别）

S2 看清重点
  ├─ 固定动作
  │   ├─ B1 任务目标提炼（JTBD格式）
  │   ├─ B2 目标冲突诊断（3个核心冲突对）
  │   └─ D2 约束条件识别（红线/硬限制/软偏好）
  ├─ 条件动作
  │   ├─ X4 品牌-空间转译（参考品牌模式，4维转译）
  │   ├─ C3 用户行为模式（6种行为模式）
  │   └─ X6 文化深度校验（4维校验+修正）
  └─ 空间命题主线推进（类型→任务→命题）

S3 定下取舍
  ├─ 冲突1裁决：品牌克制感 vs 山地感官丰富性
  ├─ 冲突2裁决：功能主义标准化 vs 在地性独特表达
  ├─ 冲突3裁决：社交开放性 vs 度假私密性
  ├─ 优先级冻结（P0-P4）
  ├─ 可牺牲项确认
  ├─ 不可突破红线
  └─ 延后处理项

S4 确认任务书
  ├─ 1. 项目定义
  ├─ 2. 空间命题（核心任务/服务对象/关键活动/决定性矛盾）
  ├─ 3. 驱动力排序（角色/权重/逻辑）
  ├─ 4. 实施边界（硬约束/软约束/Feasibility反馈）
  ├─ 5. 关键取舍（冻结优先级/牺牲项/红线/延后项）
  ├─ 6. 设计框架交付
  │   ├─ 6.1 色彩系统（4层级+禁区+气候修正）
  │   ├─ 6.2 家具策略（选型矩阵+尺度控制+在地嫁接规则）
  │   ├─ 6.3 空间尺度控制（客房/公共/窗的尺度逻辑）
  │   └─ 6.4 公共社交空间组织（社交梯度模型+空间组织+座位布局+动线设计）
  ├─ 7. 下游专家问题（F8）
  ├─ 8. 创新边界授权（F9）
  ├─ 9. 不确定性与后续展开项
  └─ 10. 来源与标注（[推断]清单+来源索引+确认记录）
```

## 关键特征

### 1. 武器协作验证

- **S1**：A1→F1→F2→F3→X1→A2→A3 顺序激活 ✓
- **S2**：B1→B2→D2（固定）+ X4→C3→X6（条件）✓
- **S3**：消费上游结果，不新增分析 ✓
- **S4**：F8→F9→G1→G2→G3 编译交接 ✓

### 2. X4 运行模式

- **判定**：HAY 不拥有该民宿，为气质参考对象
- **模式**：参考品牌转译（非旗舰模式）✓
- **输出**：4维转译（情感契约/用户认同/审美主张/禁止区）+ 空间语言参数（光/材质/比例/动线/色彩/触感）

### 3. 一主两辅方法

- **空间主线**：山地民宿集群 → 承载轻度度假活动 → 「用克制让山成为主角」
- **驱动力轴**：业主（市场辨识度）+ 客群（当代审美+自然体验）+ 环境（景观资源约束）
- **边界轴**：气候（高湿）+ 运输（山地）+ 品牌方向（HAY气质）

### 4. G1 锐度门控

- B2 冲突对描述具体、非套话 ✓
- 避免「存在一定张力」等模糊表达 ✓
- 明确「若两者都不让步，最可能牺牲的是X」✓

### 5. 任务书四类核心结构

- **空间命题结构** ✓：核心任务/服务对象/关键活动/决定性矛盾
- **驱动力结构** ✓：角色/驱动力/权重/逻辑
- **边界结构** ✓：硬约束/软约束/不在范围/Feasibility反馈
- **取舍结构** ✓：冻结优先级/牺牲项/红线/延后项

### 6. 原始问题四维度回应

- **色彩系统** ✓：4层级（基底/过渡/克制彩色/在地锚定）+ 禁区 + 气候修正
- **家具策略** ✓：选型矩阵 + 尺度控制原则 + 在地材料嫁接规则
- **空间尺度控制** ✓：客房尺度 + 公共空间尺度 + 窗的尺度逻辑
- **公共社交空间组织** ✓：社交梯度模型 + 空间组织策略 + 座位布局 + 动线设计
