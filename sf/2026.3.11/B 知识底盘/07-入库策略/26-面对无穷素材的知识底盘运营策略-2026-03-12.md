# 面对无穷素材的知识底盘运营策略（2026-03-12）

> 目的：回答一个务实问题——跨学科素材无边无际，不可能全部入库，如何更智能高效地解决？
> 核心结论：**不要试图把海洋装进水库。建一个精品弹药库（预制层），训练一个会钓鱼的人（LLM+五步法协议），然后让每次钓到的好鱼自动入库（沉淀层）。**

---

## 一、先承认现实

世界上的文学、哲学、艺术、建筑、电影、音乐、宗教、人类学素材是无穷的。逐条人工入库不可能，也没必要。

真正的问题不是"怎么把所有东西都入库"，而是：

> **怎么让系统在需要的时候，能从无穷的素材中找到对的东西，并且快速完成转译？**

---

## 二、核心策略：不是"先入库再调用"，而是"按需转译 + 逐步沉淀"

之前的思路一直在走"先把素材全部入库→再调用"的路线。面对无穷素材，应该反过来。

### 思路转变

| 之前的思路 | 现在的思路 |
|-----------|-----------|
| 先把素材全部入库 | 只预制高频命题，其余按需转译 |
| 知识底盘是"大仓库" | 知识底盘是"精品弹药库 + 转译协议" |
| LLM是调用工具 | LLM是实时转译引擎 |
| 入库是前置工作 | 入库是项目验证后的沉淀 |

### 三层架构

```
第一层：预制层（少而精，人工质量）
  ↕ 匹配不到时降级到第二层
第二层：实时转译层（LLM驱动，按需生成）
  ↕ 优质产出回流到第一层
第三层：沉淀层（项目验证后自动入库）
```

---

## 三、第一层：预制层（精品弹药库）

### 定位

只预制高频、高复用的空间状态命题。数量控制在 50-100 条。

这些是经过完整五步法验证的、多个项目反复使用的"经典命题"。例如：

- "各得其所的松弛感"（来自《清平乐》等多个来源）
- "身体被空间经历的沉浸感"（来自瓦尔斯等多个来源）
- "刚刚为你准备好的用心感"（来自一期一会等多个来源）

这层靠人工打磨，不求多，求稳。

### 选什么进预制层

不按学科选，按**业主高频表达**选——业主最常说的那些模糊词，就是预制的优先级：

| 业主高频表达 | 对应的预制命题方向 |
|------------|------------------|
| "想要有诗意" | 日常性优先于表演性、生活秩序即内容 |
| "想要高级感" | 克制优先于堆砌、细节一致性、服务精度 |
| "想要被治愈" | 身体恢复感、感官过渡、安静权 |
| "想要有文化感" | 在地生活连续性、非表皮民俗化 |
| "想要年轻" | 社交可选性、探索感、低门槛参与 |
| "想要安静" | 声学保护、社交压力控制、刺激阈值 |
| "想要有仪式感" | 序列节奏、阈限体验、渐进式揭示 |
| "想要自然" | 人工痕迹隐藏、材料老化接受、边界模糊 |

每个方向预制 3-5 条 A/B/C 级命题，总共 50-100 条就够覆盖 80% 的项目场景。

### 预制层的治理

- 每条命题必须经过至少 3 个项目验证
- 每条命题必须有完整的五步法记录（感觉核心→机制→命题→挂接→验证方法）
- 每年回评一次，淘汰低使用率条目

---

## 四、第二层：实时转译层（LLM + 五步法协议）

### 定位

当项目遇到预制层没有覆盖的需求时，LLM 实时执行五步法，按需生成命题。

关键认知：**LLM 本身就是最大的"跨学科素材库"。** 它不需要从知识底盘里检索《清平乐》，它自己就知道《清平乐》。它不需要查瓦尔斯的资料，它自己就读过 Zumthor 的文章。

所以真正需要给 LLM 的不是一个巨大的素材库，而是一套稳定的**转译协议**。

### 实时转译的触发流程

```
业主说了一句话（如"我想要有电影感"）
  → 系统先查预制命题库
  → 有精确匹配 → 直接调用预制命题进入 S2
  → 没有精确匹配 → 触发 LLM 实时转译
    → LLM 执行五步法
    → 产出候选命题进入 S2 讨论
    → S3 取舍 → S4 冻结
```

### 给 LLM 的转译协议（五步法执行指令）

```
当业主表达了一个模糊的体验诉求，且预制命题库没有精确匹配时，
执行以下五步：

Step 1：从业主的话中提取"感觉的核心"
  问自己：他说的这个词，背后真正在起作用的是什么？
  不要停留在表面词义，要追到"什么在起作用"。

Step 2：追问空间实现机制
  这个感觉在空间中靠什么成立？
  从以下维度逐一检查：距离、材料、光线、声音、温度、
  气味、节奏、视线、身体姿态、时间序列。

Step 3：翻译成空间状态命题
  格式：在[空间/时刻]，[谁]应该能[做到什么]，
  同时[不会发生什么]。
  分级：
    A（不成立则核心体验不成立）
    B（品质性，做到更好，做不到也能成立）
    C（启发性，提供方向感）

Step 4：挂到一主两辅
  明确这条命题影响的是：
    空间主线 / 驱动力修正 / 实施边界
  一条命题只挂一个主位置。

Step 5：检验可验证性
  问：这条命题能不能在建成空间中被检查？
  如果不能 → 还不够具体，回到 Step 3 继续翻译。
  同时给出风险提醒：这条命题最容易被误读为什么？
```

### 实时转译的质量保障

LLM 实时生成的命题不直接冻结，必须经过 S2 碰撞和 S3 取舍：

- 与项目现实碰撞（预算、法规、场地、运营）
- 与成事底盘的类型知识、经验规则交叉校验
- 由人（设计师或系统操作者）最终确认是否进入任务书

也就是说：**LLM 负责生成候选，人负责裁决。**

## 五、第三层：沉淀层（项目验证后回流入库）

### 定位

实时转译产出的命题，经过项目验证后，优质的自动回流到预制层。这是知识底盘自然生长的机制。

### 回流规则

```
LLM 实时生成命题 → 项目中使用 → S3 取舍 → S4 冻结
  → 项目完成后回评：这条命题有效吗？
  → 有效且通用 → 回流入库，成为预制命题
  → 有效但仅限特定场景 → 标记适用条件后入库
  → 无效或经常被降级 → 标记为低效命题，不入库
  → 产生了误导 → 标记为失败案例，供后续参考
```

### 晋升条件

- 连续 3 个不同项目中被使用且未被降级 → 升为预制命题
- 只在特定空间类型中有效 → 标记 `applicable_when` 后入库
- 连续 2 次被拒绝或产生误判 → 不入库，记录原因

### 沉淀层的意义

预制层不是一次性建完的，而是**越用越厚**：

- 第 1 年：50 条预制命题，覆盖 60% 场景
- 第 2 年：80 条预制命题（30 条从沉淀层晋升），覆盖 75% 场景
- 第 3 年：100 条预制命题，覆盖 85% 场景
- 剩余 15% 始终由 LLM 实时转译覆盖

系统不需要追求 100% 预制覆盖。有 LLM 兜底，预制层只需要覆盖高频场景。

## 六、三层协作的完整运行时序列

以一个真实场景走一遍：

```
业主说："我想要有电影感"

Step 1：查预制层
  → 预制命题库中搜索"电影感"相关命题
  → 找到 1 条 B 级命题："空间序列应有明确的章节感
    （铺垫→展开→高潮→回落），同时不会因为过度
    戏剧化而让日常使用者感到不自在"
  → 部分匹配，但不够具体

Step 2：触发实时转译
  → LLM 执行五步法
  → Step 1 感觉核心："电影感"不是要拍电影，而是
    "空间中有视角切换、有揭示时刻、有情绪转折"
  → Step 2 空间机制：转角后的视野突然打开、光线
    从暗到亮的戏剧性变化、路径中的"悬念段"
  → Step 3 生成 3 条命题：
    A级：从入口到核心空间的路径中，应至少有一个
      "视野突然打开"的揭示时刻，同时不会因为
      前段过于压抑而让使用者中途放弃
    B级：路径中的光线变化应有明确的"章节感"
      （暗→亮→暗→亮），同时不会因为反差过大
      而造成视觉不适
    C级：空间的"高潮点"应该是被路径自然引导
      到达的，而不是一进门就全部展示

Step 3：命题进入 S2 碰撞
  → 与项目现实碰撞（场地条件、预算、动线需求）
  → A 级命题成立，场地有天然高差可利用
  → B 级命题需要改写，消防通道不允许过暗段

Step 4：S3 取舍 → S4 冻结
  → 2 条进入任务书，1 条作为设计指引

Step 5：项目完成后回评
  → A 级命题在 3 个后续项目中也被使用
  → 晋升为预制命题入库
```

## 七、人工只需要做两件事

整个策略下来，人工的工作量被压缩到最小：

### 1. 打磨预制层的经典命题

这是一次性工作（后续只需维护）：

- 从业主高频表达出发，梳理 8-10 个核心方向
- 每个方向预制 3-5 条命题
- 每条命题走完整五步法，确保有验证方法和风险提醒
- 总工作量：约 50-100 条，集中 2-3 周可完成初版

### 2. 审核实时转译的质量

这是持续性工作，但工作量不大：

- 每个项目中 LLM 实时生成的命题，由设计师或操作者在 S2/S3 中审核
- 审核标准：命题是否可验证？风险提醒是否到位？挂接位置是否准确？
- 项目完成后，标记哪些命题值得回流入库

**不需要人工去读所有的诗歌、哲学、电影。LLM 已经读过了。人只需要审核 LLM 的转译质量。**

---

## 八、这个策略解决了什么问题

1. **不需要穷举入库** — 无穷的素材不需要全部预先处理
2. **预制层保持精品** — 只有经过验证的命题才入库，避免底盘膨胀
3. **LLM 的知识被制度化利用** — LLM 本身就是最大的跨学科素材库，五步法是让它稳定输出的协议
4. **系统会自然成长** — 每个项目都可能贡献新的预制命题，底盘越用越厚
5. **人工成本可控** — 人只做打磨和审核，不做穷举和搬运

---

## 九、一句收尾

> **知识底盘的终极形态不是一个装满素材的仓库，而是一套让 LLM 稳定产出高质量空间判断的协议，加上一个经过项目验证的精品命题库。协议保证质量下限，命题库提升效率上限，沉淀机制让系统越用越聪明。**
