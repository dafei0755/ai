# 专业知识底盘 · 目录导航

> 这个目录讲的是“系统用什么知识做判断”。  
> 现已按主题拆分为 6 个子目录：基础总纲、类型知识、跨域桥接、人物量化、方法治理与运行、空间分类。

---

## 推荐阅读路径

建议按下面的顺序阅读：

1. **基础总纲**：先理解底盘为什么存在、语义基座是什么、四层结构怎么分。  
2. **空间分类**：再看空间分类与空间类型如何分层、归桶、进入后续路由。  
3. **类型知识**：再看空间类型知识如何变量化、规格化、可入库。  
4. **跨域桥接**：再进入文学/电影/心理学/宗教/奢侈品等跨域知识如何转译。  
5. **人物量化**：补上“人物 → 设计人格 → 空间倾向”的中层桥梁。  
6. **方法治理与运行**：最后进入一主两辅挂接、IR 协议、案例演算、入库治理与运行时闭环。
