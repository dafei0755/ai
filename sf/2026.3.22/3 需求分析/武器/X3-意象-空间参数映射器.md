# X3 — 意象-空间参数映射器

> **组别**：X 组（场景扩展·新增）| **阶段**：S1 后 / B1 之前 | **类型**：后台·诗意输入预处理器
> **优先级**：P1 | **触发**：输入语言被检测为「象征型/隐喻型」时 | **消费方**：B1、F3

---

## 一分钟定义

当客户用**象征性、诗意性、隐喻性语言**描述需求时，**提取其中的情绪参数和空间氛围关键词**，而不是强行将其转换成功能目标——保护诗意表达不被 JTBD 结构碾碎。

---

## 功能详述

B1 的 JTBD 框架（「当[情境]，用户想要[事]，因为[动因]」）是针对「目标明确的功能需求」设计的。但空间设计领域里，有一类请求的核心在于**情绪体验、意境氛围、象征精神**——这类需求一旦被强制转换成功能目标，意义损失不可逆。

X3 的任务是：**检测诗意请求 → 提取情绪/感知参数 → 以空间语言重新表达 → 输出给 B1 作为修正补充（而非替换）**。

### 诗意请求识别信号

| 信号类型 | 举例 |
|---------|------|
| 直接意象描述 | 「月亮落在结冰的湖面上」 |
| 精神气质描述 | 「一代创业者的精神结构」「赫本精神」 |
| 品牌/人物精神转移 | 「Tiffany 的被珍视感」「安藤忠雄为其设计」 |
| 否定式描述 | 「不要像住宅感」「避免符号化中式」 |
| 哲学/存在主义描述 | 「可以与自己对话的空间」「消失在环境中」 |

### 映射流程（3 步）

**Step 1：意象解构**  
把象征语言拆解为感知维度：

| 意象 | 光感 | 温度感 | 声音感 | 材质感 | 空间张力 |
|-----|-----|-------|-------|-------|---------|
| 月亮落在结冰的湖面 | 冷白漫射·无阴影 | 极低·静止感 | 极静·空旷回响 | 硬光滑·无纹理 | 水平延展·压低 |
| 安藤忠雄精神性 | 定向强光·强阴影 | 凉·厚重感 | 混凝土吸声·沉默 | 粗粝·有质量感 | 纵向压缩·集中 |

**Step 2：参数化输出**  
把感知维度翻译成空间设计语言参数：

```python
image_space_params: {
    "luminosity":     "漫射冷白；避免点光源",
    "thermal_feel":   "低温材质（石材/玻璃/金属）为主",
    "acoustic_feel":  "强吸声；避免硬面回响",
    "material_axis":  "光滑硬质为主；布艺减至最低",
    "spatial_tension":"水平延展；层高压低；视线引向远端",
    "forbidden_zone": ["暖色光源", "木纹肌理", "圆弧形式"],
    "must_have_feel": ["静止感", "时间暂停感", "反射界面"]
}
```

**Step 3：B1 修正标注**  
在 B1 的 JTBD 输出后附加一条 `poetic_intent_note`，标注原始意象参数，防止后续武器把诗意剥离：

```
[poetic_intent_note]: 本项目的核心诉求包含无法被 JTBD 完全捕获的意境意图。
参见 image_space_params：空间氛围参数应全程参与 S3/S4 的设计方向决策。
```

---

## 输入

```
raw_input_text          # 原始输入（检测象征性语言）
A1_outputs              # A1 已提取的偏好信号（作为上下文补充）
```

---

## 输出

```python
image_space_params: {
    "detected_poetic_input": True,
    "original_metaphor": "月亮落在结冰的湖面上",
    "luminosity": str,
    "thermal_feel": str,
    "acoustic_feel": str,
    "material_axis": str,
    "spatial_tension": str,
    "forbidden_zone": List[str],
    "must_have_feel": List[str],
    "confidence": float          # 解构置信度，<0.5 时增加一个确认问题
}
```

---

## 激活条件

A1 信号解析后，检测到以下任一：
- `preference_signals` 中包含意象型描述（非品牌型、非风格标签型）
- 输入文字包含「精神」「气场」「意境」「感觉像」「如同」等隐喻触发词
- 品牌/人物名称作为空间精神描述（Tiffany、安藤忠雄、赫本、苏东坡等）

---

## 执行方式

- LLM 主导（象征语义理解）
- 低置信度（< 0.5）时：输出草案 + 1 个确认问题（向用户确认映射方向是否准确，不展示技术参数，只展示「你说的这种感觉，我理解为……是这样吗？」）

---

## 用户交互

**有（仅低置信度时，最多 1 个问题）**。格式示例：

> 「你提到『月亮落在结冰的湖面上』——我理解你在寻求一种极静、冷白、硬质光滑、时间静止感的空间氛围，并希望避免暖色和木质感。是这样吗？」

---

## 协作关系

```
上游（依赖）：← A1 偏好信号
下游（补充）：→ B1（附加 poetic_intent_note，JTBD 不替代意象参数）
             → F3（关键洞见应引用意象参数，不能只提功能）
             → G1（锐度检查时，image_space_params 是额外的「锐度参考系」）
```

---

## 常见误用

1. 用 X3 的输出**替换** B1 的 JTBD（两者并存，JTBD 捕捉功能层，X3 捕捉情绪层）
2. 在置信度高时仍然问用户「你说的是这个意思吗？」（置信度高的时候直接输出，不必确认，避免增加认知负担）
