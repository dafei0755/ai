# X7 — 商业可行性验证器

> **组别**：X 组（场景扩展·新增）| **阶段**：S3（与 D1 并行）| **类型**：后台·商业逻辑校验
> **优先级**：P2 | **触发**：X1 判断为商业竞争型/品牌旗舰型时 | **消费方**：D1（补充商业维度）

---

## 一分钟定义

**从「投入-产出」和「竞争差异化」两个维度，检验当前设计方向是否在商业上成立**——防止设计方向在美学上有说服力，但在商业逻辑上无法自洽。

---

## 功能详述

D1（设计前提校验器）从专业设计视角挑战方案前提。但商业项目还需要另一层校验：设计方向是否能支撑项目的商业目标（客流/坪效/溢价/品牌价值/差异化定位）。

X7 是 D1 在商业维度的延伸，专门为「设计即商业策略」类项目服务。

### 三个核心校验维度

**维度 1：视觉杠杆效率**  
「哪些设计投入（预算/注意力）能获得最高的感知溢价回报？」

| 高杠杆典型投入 | 低杠杆典型陷阱 |
|-------------|-------------|
| 入口第一印象（客流量最大触点） | 储藏区的高端材料 |
| 核心公共区域的视觉焦点（100%曝光） | 隐蔽区域的精工细节 |
| 灯光系统（整体氛围塑造，相对低成本） | 定制家具（高成本低可见度） |
| 标志性记忆点（社交媒体可传播性） | 大体量软装（视觉贡献低） |

**维度 2：差异化竞争有效性**  
「这个设计方向，能否形成竞争对手短期内学不走的优势？」

| 竞争校验问题 | 答案类型 |
|-----------|---------|
| 这个设计方向的核心竞争差异是什么？ | 文化/服务/体验/人群/效率 |
| 这个差异竞争对手是否可以在 12 个月内复制？ | 可/不可，说明理由 |
| 这个方向是否与目标客群的消费决策点直接相关？ | 是/否 |

**维度 3：运营成本-体验质量平衡**  
「这个设计方向的运营成本结构是否合理？」

| 运营成本风险点 | 扫描方向 |
|-------------|--------|
| 高维护材料 | 天然石材/定制金属/大面植物墙——维护成本是否可持续？ |
| 高能耗设备 | 感应照明系统/水景/温控展示柜——运营期能耗是否合理？ |
| 人力依赖动线 | 是否存在需要持续人工维护才能维持设计感的元素？ |

## 输入

```
design_direction_draft  # 当前设计方向草案
project_economics: {
    budget_total:       # 总预算（如已知）
    target_revenue:     # 目标收入指标（客单价/坪效/入住率等）
    competitive_context # X1 判断的商业子类型 + 竞争对手信息
}
```

## 激活条件

X1 判断为：
- 品牌旗舰型
- 商业竞争型
- 混合使用型

**轻量触发**（仅跑维度 3 运营成本）：个人住宅中出现明显高维护设计元素。

---

## 协作关系

```
上游（依赖）：← X1 商业类型判断 ← D1 设计前提挑战（并行运行）
下游（供给）：→ D1（商业维度补充，D1 输出时附带 X7 的商业基础）
             → S4 冻结机制（商业可行性是张力决策的重要权重维度之一）
             → F8（X7 的风险点会转化为专家交接问题）
```

---

## X7 vs D1 的分工

| | D1 设计前提校验器 | X7 商业可行性验证器 |
|-|-----------------|------------------|
| 挑战视角 | 设计专业（美学/功能/技术） | 商业逻辑（坪效/竞争/运营） |
| 内部辩论 | 保守/激进/外行/专家 4 方 | 投资人视角 + 消费者决策视角 |
| 输出 | 设计核心挑战（1~2 条） | 商业风险/杠杆建议（1~3 条） |
| 触发 | S3 必说 | S3 条件触发（商业类项目） |

---

## 常见误用

1. 用 X7 为纯个人住宅审美方向做「商业性评估」（纯自住项目不触发）
2. X7 的「低杠杆」判断变成「不让设计师做精细化设计」（X7 是关于投入分配，不是反对品质）
