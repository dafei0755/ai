# Y1 — 机构战略意图生成器

> **导航提示：** 若你在看机构、品牌、商业类复杂项目，建议先读 [README](README.md) 与 [04-场景扩展与机构项目武器](04-场景扩展与机构项目武器-2026-03-11.md)；本文是机构项目的主引擎型武器。

> **组别**：Y 组（战略升级·新增）| **阶段**：S2（机构项目主引擎）| **类型**：互动·机构版主分析器
> **优先级**：P0 | **触发条件**：X1 判断为 `机构/商业` 或 `混合型` | **消费方**：B1（机构版替代）、D1、S4

---

## 一分钟定义

当客户不是个人而是机构时，**用“战略意图 + 成功标准 + 关键约束”三元组替代个人版 JTBD**，把项目从“客户想要什么风格”升级为“组织为什么做这件事、如何判断它成功、哪些边界不能碰”。

---

## 功能详述

B1 的 JTBD 适合个人项目，但对机构客户会出现错位：机构项目的核心不是“某个人想完成什么任务”，而是一个组织要在商业、品牌、治理、运营之间完成某种战略动作。

Y1 的作用，就是成为**机构版 B1 主引擎**。

### 输出三元组

| 维度 | 核心问题 | 输出字段 |
|-----|---------|---------|
| **战略意图** | 组织为什么现在做这件事？ | `strategic_intent` |
| **成功标准** | 这个项目成功时，组织内部会用什么标准判断？ | `success_criteria` |
| **不可突破边界** | 哪些约束如果被触碰，项目即使漂亮也算失败？ | `strategic_red_lines` |

### 常见机构战略意图类型

| 类型 | 典型项目 | 战略意图表达 |
|-----|---------|-------------|
| **品牌升级** | 酒店旗舰店、旗舰零售 | 重建品牌认知、建立新一代形象 |
| **竞争防御** | 商业街区、写字楼更新 | 抵御对手分流、重构差异化优势 |
| **效率优化** | 医院、办公、物流空间 | 提升运营效率、减少浪费 |
| **公共治理** | 社区中心、城市更新 | 提升公共服务与社会接受度 |
| **招商与资本化** | 开发区展示中心、样板示范区 | 提高招商转化与资产溢价 |

### 输出格式示例

```python
institutional_strategy_profile: {
    "strategic_intent": "通过旗舰空间重建 Ascot 在高端长住市场中的‘新一代精致生活’认知",
    "success_criteria": [
        "目标客群愿意将项目视为区别于传统五星的独立选择",
        "入住率与复购率具备可验证提升",
        "品牌总部认可其为下一阶段标准样板"
    ],
    "strategic_red_lines": [
        "不能落回传统五星豪华公式",
        "不能以艺术性牺牲运营效率",
        "不能让单房模型失去 600 元价位的超值感"
    ],
    "org_tradeoff_core": "品牌升级 vs 成本控制 vs 运营复制性"
}
```

## 激活条件

- X1 判断为 `机构/商业`
- 或 `混合型` 且项目存在明确组织目标（品牌、招商、竞争、防御、治理）

---

## 用户交互

**有（最多 2 个问题）**。用于逼出组织真正的成功标准：

> 「如果项目完工一年后，内部有人说‘这项目值了’，他们最可能是基于什么判断？」

---

## 协作关系

```
上游（依赖）：← X1 客户端类型分级
下游（供给）：→ D1（挑战战略前提）
             → X7（商业可行性围绕 success_criteria 校验）
             → S4（围绕 org_tradeoff_core 做冻结）
             → F8/F9（专家交接与授权边界）
```

---

## 常见误用

1. 把 Y1 再写成个人式 JTBD（机构项目不需要“当我…我想…”）
2. 把“成功标准”写成美学描述（成功标准必须能被组织内部判断，而非只让设计师感动）
