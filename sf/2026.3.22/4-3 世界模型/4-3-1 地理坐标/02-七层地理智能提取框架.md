## 一、框架概览

`GeoCoordinateBaseline` 的深度编译（Node3 步骤 3.S.0）围绕七个层次逐层展开。每一层提取的不是信息本身，而是**可被下游直接消费的约束与机会结论**。

| 层级 | 层名 | 核心提取目标 | 主要下游消费者 |
|------|------|------------|--------------|
| 第一层 | 物理地理 | 地形/海拔/气候/景观资源 | SPG `strategy_scopes`、WorkMap 气候专属任务 |
| 第二层 | 到达与可达 | 到达方式/时长/疲劳值/首感机制 | AlignedBrief 目标体验、WorkMap 设计任务优先级 |
| 第三层 | 城市语义 | 区域定位/客群信号/情绪气质 | AlignedBrief 目标对象、3.S.1 主线问题 |
| 第四层 | 文化基因 | 地域文化/风格禁区/在地工艺 | 3.S.1 边界压缩轴、SPG 材料与叙事策略 |
| 第五层 | 市场环境 | 竞争格局/价格带/淡旺季 | AlignedBrief 成功标准、WorkMap 资本与运营策略 |
| 第六层 | 约束与机会 | 硬约束/法规限制/独特机会/风险 | 3.S.1 边界压缩轴（直接输入）、场地约束卡/机会卡 |
| 第七层 | 世界模型锚点 | 地点的不可替代身份与空间命题 | 3.S.1 主线问题（空间命题起点）、SPG 核心叙事 |

## 二、各层详解

### 第一层：物理地理

**提取目标：** 地点的自然物理条件，是所有设计决策的基础参照系。

| 提取维度 | 具体内容 |
|---------|----------|
| 坐标与海拔 | 经纬度精确值、海拔高度（米）、地形坡度 |
| 气候带 | 气候类型（温带/亚热带/高原等）、年均温、极端温差 |
| 降水与湿度 | 年降水量、梅雨期、干湿季节、相对湿度均值 |
| 风向与风压 | 主导风向、最大风速、冬夏季风差异 |
| 日照特征 | 年日照时数、采光需求级别、季节性日照变化 |
| 景观资源 | 可见山体/水域/林地/城市界面、借景方向与距离 |
| 地质与地形 | 坡地/台地/平坦/滨水、地质灾害风险级别 |

**下游传播路径：**
- `physical_context` → SPG `zone_constraints`（特殊空间需求：冬季暖区/防潮层/景观阳台）
- `physical_context` → WorkMap 气候专属任务（高海拔：耐候材料研究/排潮系统/采暖方案）
- `physical_context` → FloorPlanIR 几何约束（山地错层、台地布局、日照开口朝向）
- `physical_context` → ElevationIR 材质策略（防雨深挑檐/多雨禁大面积玻璃幕墙）

---

### 第二层：到达与可达（交叉校验新增层）

**提取目标：** 人的到达过程是空间体验的第一章，直接决定首感设计策略。（参考1补充，主架构原六层缺失此层）

| 提取维度 | 具体内容 |
|---------|----------|
| 宏观交通 | 距最近机场/高铁/高速公路时长 |
| 最后5公里体验 | 道路状况、景观过渡、道路复杂度 |
| 抵达方式分布 | 自驾/大巴/步行/摆渡车比例 |
| 停车与落客 | 停车位规模、落客动线、停车心理感受 |
| 步行转换 | 车到门口的步行体验（坡道/院子/台阶） |
| 到达疲劳值 | 评估级别：低（城市便达）/ 中（2小时自驾）/ 高（偏远长途） |
| 首感设计窗口 | 基于疲劳值推断入场情绪修复需求优先级 |

**下游传播路径：**
- `accessibility_context` → AlignedBrief 目标体验（首感情绪修复 or 仪式进入）
- `accessibility_context` → WorkMap 到达动线设计任务（高疲劳值项目必须设"到达仪式区"）
- `accessibility_context` → 梦幻团队团队席位（景观动线设计师、户外体验顾问）
- `accessibility_context` → 场地约束卡/旅程卡（到达体验描述）

**案例速查：**

| 项目 | 疲劳值 | 首感策略 |
|------|-------|---------|
| 峨眉山七里坪 | 高（自驾2.5小时+山路蜿蜒） | 到达即减压：宽停车场/遮雨落客/温暖照明/安静接待 |
| 深圳湾壹号 | 低（地铁直达/城市中心） | 到达即身份感：精准门卫/无等待感/仪式感电梯厅 |

---

### 第三层：城市语义

**提取目标：** 地点在人的认知图谱中的"隐含身份"，决定目标客群与期待基准。

| 提取维度 | 具体内容 |
|---------|----------|
| 城市层级 | 一线/新一线/省会/旅游城市/特色小镇 |
| 区域标签 | CBD / 文旅目的地 / 老城核心 / 度假区 / 产业园 |
| 客群信号 | 主力客群职业画像、消费水平、旅行动机 |
| 情绪气质（emotional_tone）| 空间应该唤起的主导情绪关键词：山野沉浸/云端顶级/松弛疗愈/都市封面/老城市井 |
| 地标邻近 | 主要景点/商圈/自然之间的从属关系 |
| 区域发展阶段 | 成长期/成熟期/饱和期，影响差异化空间 |

**下游传播路径：**
- `urban_semantic.demographic_signal` → AlignedBrief 目标对象（谁来/为什么来）
- `urban_semantic.emotional_tone` → SPG 风格锚点（核心感知词直接进 strategy_scopes）
- `urban_semantic` → 3.S.1 辅轴A（驱动力修正轴的外部信号来源）
- `urban_semantic` → 梦幻团队（区域市场专家、城市社会学研究员席位触发）

---

### 第四层：文化基因

**提取目标：** 地点的文化合法性边界，是风格决策的上位判断框架。

| 提取维度 | 具体内容 |
|---------|----------|
| 在地文化 | 民族/地方文化主题、历史特征 |
| 历史脉络 | 建筑历史、场地记忆、文化遗产级别 |
| 在地建筑语言 | 传统建筑形制、材料体系、构造工艺 |
| 手工艺传统 | 可借用的地方工艺母题（竹编/青砖/夯土/石材） |
| 风格禁区（taboo_styles）| 在该区域会产生文化冲突或审美排斥的风格列表 |
| 文化叙事张力 | 地方性是否足够强以支撑叙事，还是中性城市语境 |

**下游传播路径（含最强约束）：**
- `cultural_dna.taboo_styles` → SPG `style_boundary`（**硬约束，治理规则3：不得被后续节点静默覆盖**）
- `cultural_dna` → 3.S.1 辅轴B（边界压缩轴的文化禁区输入）
- `cultural_dna.craft_traditions` → WorkMap 在地材料采样任务 / 工匠顾问席位触发
- `cultural_dna` → VizSpec 材质叙事策略（本地材料与工艺优先出现在视觉化中）

---

### 第五层：市场环境

**提取目标：** 项目所处的商业生态，是盈利模型与差异化策略的现实基准。

| 提取维度 | 具体内容 |
|---------|----------|
| 竞品格局 | 直接竞品数量/级别/分布密度 |
| 替代消费 | 周边强势餐饮/娱乐/景区对本项目的替代度 |
| 价格带信号 | 周边消费价格带、本项目定价空间 |
| 旅行者动线 | 客群通常的行程串联方式（是目的地还是途经点） |
| 淡旺季规律 | 旺季峰值时间、淡季时长、淡季收入维持策略 |
| 需求驱动 | 主要驱动力（自然/文化/商务/社交/疗愈） |

**下游传播路径：**
- `market_context` → AlignedBrief 成功标准（盈利模型合理性）
- `market_context.competitive_gap` → 场地机会卡（差异化竞争缺口）
- `market_context.seasonality` → 经营影响卡（淡季空间兼容性要求）
- `market_context` → 3.S.1 辅轴A（市场需求驱动修正）
- `market_context` → WorkMap 资本策略任务（竞品分析/定价校准）

---

### 第六层：约束与机会

**提取目标：** 综合上述各层，将判断结论结构化为可直接指导设计的约束清单与机会清单。

| 提取维度 | 具体内容 |
|---------|----------|
| 地理硬约束 | 气候/地形带来的不可更改设计限制 |
| 法规约束（新增）| 城市风貌管控、退界限高、历史保护要求、消防规范特殊性 |
| 风格约束 | `taboo_styles` 集合（来自文化基因层） |
| 独特机会 | 该地点在设计上不可复制的优势（景观资源/气候稀缺性/文化张力） |
| 风险标记（risk_flags）| 可能导致方案失败的地理相关风险 |
| 供应链约束（新增）| 偏远地点带来的材料运输与施工可行性限制 |

**下游传播路径：**
- `constraints_and_opportunities.hard_geo_constraints` → 3.S.1 辅轴B（边界压缩轴）
- `constraints_and_opportunities.unique_opportunities` → WorkMap 专题任务（每一个独特机会对应至少一个专题任务）
- `constraints_and_opportunities.risk_flags` → WorkMap 任务优先级（高风险任务前置）
- `constraints_and_opportunities.regulatory_constraints` → FloorPlanIR 法规边界约束

---

### 第七层：世界模型锚点

**提取目标：** 对该地点"不可替代身份"的完整命题表达，是解题思路主线问题的起点。

| 提取维度 | 具体内容 |
|---------|----------|
| 地点名片 | 这个地点最独特的1-2个属性组合（稀缺性描述） |
| 核心命题 | "在这里做空间设计，最不能绕开的核心问题是什么" |
| 顺势与逆势 | 哪些设计动作是"顺着地点的势"，哪些是"逆势而为" |
| 空间命题起点 | 面向 3.S.1 的主线问题雏形（地理决定的问题框架） |

**下游传播路径：**
- `world_model_anchor` → 3.S.1 主线问题（空间命题起点，是主线问题的地理注脚）
- `world_model_anchor` → SPG `core_narrative`（设计宪法的核心叙事层）
- `world_model_anchor` → AlignedBrief 核心假设（最后需要被验证的地理假设）

## 三、案例示范：峨眉山七里坪 vs 深圳湾壹号

> 本案例用于验证七层框架是否能将差异地理坐标转化为差异设计命题

### 3.1 峨眉山七里坪

| 层级 | 提取结论 |
|------|---------|
| 物理地理 | 海拔1100m+，湿冷多雾，降水丰富，林木茂密，山体景观主导 |
| 到达与可达 | 成都自驾2.5h，山路蜿蜒，疲劳值高，首感修复需求强 |
| 城市语义 | 康养度假区，客群以成都/重庆家庭/情侣/自驾康养为主；情绪气质：山野沉浸/松弛疗愈 |
| 文化基因 | 峨眉佛教文化、自然生态语境、忌讳欧式地中海/工业风 |
| 市场环境 | 周边农家乐竞品强，餐饮同质化，淡旺季差异明显（夏旺冬淡） |
| 约束与机会 | 约束：高湿易霉/施工难度/材料运输；机会：山景独占性/气候疗愈差异化/康养叙事稀缺 |
| 世界模型锚点 | "峨眉山的空气本身是产品，空间的任务是让人降下来、慢下来" |

**设计命题输出：**
```
主线问题：这个民宿如何成为疲惫都市人的"降落点"而不是"游客目的地"？
辅轴A（驱动力修正）：客群不是"旅游者"，而是"逃离者"，空间语言需要主动回应这种渴望
辅轴B（边界压缩）：禁用一切"表演性"风格（欧式/地中海/工业时髦），禁用难以维护的精细材料
风格禁区：欧式尖顶、地中海白墙蓝顶、Heavy Industrial风格
优先任务：到达仪式设计、山景取景框策略、防潮排湿系统、淡季兼容性方案
```

---

### 3.2 深圳湾壹号

| 层级 | 提取结论 |
|------|---------|
| 物理地理 | 海拔5m，亚热带沿海，强日照，海景资源，高层建筑群 |
| 到达与可达 | 市中心直达，地铁/豪华接送，疲劳值极低，首感期待值极高 |
| 城市语义 | 城市封面、塔尖人群、国际化、高净值客群；情绪气质：云端顶级/身份表达/都市封面 |
| 文化基因 | 国际消费文化、深圳湾的"开放精英"语境、地中海/工业风此处反而适合现代国际路线 |
| 市场环境 | 竞品稀少（高端住宅市场份额有限），配套餐饮强势，停留以社交展示为主 |
| 约束与机会 | 约束：必须回应身份符号期待/否则"摔价"；机会：海景天际线/圈层社交/收藏展示 |
| 世界模型锚点 | "深圳湾壹号的坐标代表一种生活宣言，空间的任务是让这种宣言变得可触摸" |

**设计命题输出：**
```
主线问题：如何让空间成为塔尖人群无声的身份宣言，而非财富的通俗展示？
辅轴A（驱动力修正）：客群不是"买房者"，而是"选择某种生活方式的人"，空间应回应生活方式
辅轴B（边界压缩）：禁用一切"乡村疗愈""手作慢生活"叙事，禁用过度装饰的"土豪感"
风格禁区：乡野质朴/农家手作/过度繁复装饰
优先任务：海景视廊最大化、社交动线与私密动线分离、材质精度升级、会客场景仪式感
```

## 四、3.S.0 编译流程（七层运行顺序）

```
① geo_pin 确认（Node1动作，进入此步骤的前提）
    ↓
② 第一层：物理地理提取（气候/海拔/地形/景观）
    ↓
③ 第二层：到达与可达分析（交通/疲劳值/首感窗口）
    ↓
④ 第三层：城市语义解读（区域定位/客群信号/情绪气质）
    ↓
⑤ 第四层：文化基因扫描（禁区识别/在地工艺/叙事合法性）
    ↓
⑥ 第五层：市场环境分析（竞品/价格带/淡旺季）
    ↓
⑦ 第六层：约束与机会汇总（生成约束卡/机会卡/旅程卡/经营影响卡）
    ↓
⑧ 第七层：世界模型锚点提炼（主线问题雏形）
    ↓
⑨ GeoCoordinateBaseline v1.0 冻结
    ↓
⑩ 向 3.S.1 解题思路交付基线
```

## 五、下游传播总规则表

### 5.1 → 3.S.1 解题思路（一主两辅映射）

| 解题思路轴 | 来自 GeoCoordinateBaseline 字段 |
|-----------|-------------------------------|
| 主线问题 | `world_model_anchor.core_proposition`（地理命题起点） |
| 辅轴A（驱动力修正轴）| `urban_semantic.demographic_signal` + `cultural_dna.cultural_narrative` + `market_context.demand_drivers` |
| 辅轴B（边界压缩轴）| `constraints_and_opportunities.hard_geo_constraints` + `cultural_dna.taboo_styles` + `market_context.seasonality_pattern` |

### 5.2 → 3.S.2 工作地图

| WorkMap 内容 | 来自 GeoCoordinateBaseline |
|------------|---------------------------|
| 专业席位触发 | 地理特殊性 → 特殊专家（高海拔→结构/暖通；强文化语境→人类学/工艺顾问） |
| 任务优先级排序 | `constraints_and_opportunities.risk_flags` |
| 地理专属任务包 | `unique_opportunities`（每个机会对应至少一项专题任务） |
| 到达体验设计任务 | `accessibility_context.arrival_fatigue` &gt; 中 → 触发到达仪式设计任务 |

### 5.3 → 4.1 梦幻团队

| 席位触发条件 | 地理字段 |
|-----------|---------|
| 在地工匠顾问 | `cultural_dna.craft_traditions` 非空 |
| 山地/高海拔专项工程师 | `physical_context.terrain_type = mountain` |
| 气候耐久专项顾问 | `physical_context.humidity_level > 高` 或 `climate_zone = 高原/滨海` |
| 在地文化研究员 | `cultural_dna.cultural_pressure = strong` |
| 区域市场分析师 | `market_context.competitive_density > 中` |

### 5.4 → 4.2 任务清单（地理坐标派生任务）

| 任务类型 | 触发字段 |
|--------|---------|
| 气候与季节策略 | `physical_context.climate_zone` |
| 到达动线与首感设计 | `accessibility_context.arrival_fatigue >= 中` |
| 竞品差异化扫描 | `market_context.competitive_density > 低` |
| 景观资源分配 | `physical_context.landscape_resources` 含高价值景观 |
| 风格禁区执行报告 | `cultural_dna.taboo_styles` 非空（确认传播至 SPG） |
| 在地材料样品采集 | `cultural_dna.craft_traditions` + `physical_context.local_material_base` |
| 法规合规前置 | `constraints_and_opportunities.regulatory_constraints` 非空 |
| 淡旺季运营模型设计 | `market_context.seasonality.peak_off_ratio > 3:1` |
