## 〇、追问的根本原则

### 钱不是"赚来的"，是"被给予的"

这是商业设计方法论最根本的认知转换。

```
旧认知：我要赚钱 → 我要做好设计 → 钱自然来
新认知：消费者主动把钱给你 → 是因为你提供了他认为值得的交换
```

**追问的本质**：把所有单方面的意图（"我要赚钱"/"我要做好这个项目"），
追穿到**双方必须同时成立的条件**——只有当消费者那一侧的逻辑也成立，项目才真正成立。

### 追问的终止条件

追问不是无限递归，有两个合法终止点：

```
终止点 A — 触到"人性基础层"
  追到"为什么他愿意这样做"的最底层动机，无需再往下拆
  例：他让你赚钱，是因为在你这里他获得了身份认同感
      "身份认同"是人性基础，无需继续追

终止点 B — 触到"设计能影响的最末端"
  追到空间设计可以直接服务的具体人类感知点
  例：他愿意回来，是因为那个角落让他感到"被看见"
      "被看见"是设计可以服务的真实目标，停止追问，转入设计动作
```

**禁止的终止方式：**
- 停在"赚钱"或"做好这个项目"（目的层，未触达条件层）
- 停在"氛围好"或"体验优"（感受描述，无法驱动设计）
- 停在"用户满意"（结果愿望，不是条件）

## 一、第一追问：谁给你钱？

> **目的：** 把"赚钱"具体化到一个真实的人，消灭抽象化的"目标用户"

### 追问链

```
这个项目要赚钱
  ↓
赚谁的钱？
  → 这个人是谁？（年龄/收入层/生活圈/消费习惯）
  → 他为什么有这笔钱可以花？（收入来源/消费能力的基础）
  → 他在什么具体状态下做出这个消费决定？
    （什么时间 / 什么心情 / 什么场合 / 和谁一起）
  → 他做这个消费，是习惯行为，还是特殊决定？
    （频次如何 / 是不是需要理由 / 需要什么理由）
```

### 系统追问话术

```
Q1-1 你最想赚哪类人的钱？能不能描述他/她的一个典型的下午？
Q1-2 他今天为什么会出现在你这里，而不是在其他地方？
Q1-3 他口袋里的这笔钱，他原本打算怎么花？你在跟什么竞争？
Q1-4 他是第一次来，还是老客？两者有哪些不同的动机？
```

### 合格答案的标准

```
不合格：
  × "25-40岁的都市白领女性"
  × "追求品质生活的消费者"

合格：
  ✓ "周末带伴侣或闺蜜'打卡'的28-35岁女性，预算500以内，决策在小红书上完成"
  ✓ "出差的中年商务男性，公司报销，要的是'不出错'和'有面子带客户'"
```

## 二、第二追问：凭什么他选你？

> **目的：** 锁定真实竞争场域，建立可检验的"比较胜出"逻辑

### 追问链

```
他为什么让你赚，而不是让别人赚？
  ↓
他的比较对象是谁？
  → 同类竞品中，他知道哪几个？
  → 他通常怎么做比较？（价格/口碑/朋友推荐/平台搜索排名）
  → 他凭什么判断你比别人好？（他能看到和感知到的依据）
  → 这个判断发生在什么时刻？（决定性选择瞬间）

还要追：
  → 如果他不选你，他会干什么？
    （选竞品 / 不消费 / 自己解决）
    ← 这是你真正的竞争对象
```

### 系统追问话术

```
Q2-1 如果他今天不来你这里，他最可能去哪里？
Q2-2 他是怎么找到你的？在那个找到你的瞬间，他的备选项还有谁？
Q2-3 他决定"就是这里了"的那一刻，是什么让他做了这个决定？
Q2-4 你的竞争对手里，有没有一个你真心认为比你做得好的地方？
      （这个问题逼出真实的能力边界）
```

### 高频陷阱（系统识别并提醒）

```
陷阱1：业主说"我没有竞争对手，我们是独特的"
  → 系统反问："如果你明天关门，你的客户会去哪里？那就是你的竞争对手。"

陷阱2：比较依据是业主自己认为的，而非消费者真实的判断标准
  → 系统反问："你觉得你的优势是___，但你的客户在评论里说的是什么？"

陷阱3：选择原因是口号式的（"我们服务更好"）
  → 系统反问："服务好，体现在哪三个他能感知到的具体时刻？"
```

## 三、第三追问：凭什么他心甘情愿？

> **目的：** 建立"消费者视角的价值闭环"——从预期到体验到事后感受

### 追问链

```
凭什么他不觉得吃亏，反而觉得值？
  ↓
买单前他相信什么？（预期如何建立的）
  → 他在哪里看到了你？（触达渠道）
  → 他看到的那个画面/描述，给他建立了什么预期？
  → 这个预期是真实可兑现的，还是夸大的？

买单中他感受到什么？（体验 vs 预期）
  → 到达的那一刻，预期兑现了吗？
  → 消费过程中，有没有让他"不对"的时刻？
  → 有没有让他"比预期好"的惊喜时刻？

买单后他说了什么？（记忆与传播）
  → 他事后对朋友怎么描述这次体验？
  → 他会推荐吗？他用什么理由推荐？
  → 如果他不满意，他的第一个动作是什么？
```

### 系统追问话术

```
Q3-1 他在决定来之前，脑子里对这里的想象是什么？
Q3-2 他第一次到达的时候，最先注意到的是什么？
Q3-3 这次消费里，有没有一个让他"哎，有点意思"的瞬间？
Q3-4 离开之后，他对朋友说的第一句话是什么？
Q3-5 如果他觉得不值，他不会说什么，他会直接做什么？
```

### 价值闭环检验（系统必须完成）

```
预期建立 → 体验兑现 → 事后感受
  ↓           ↓           ↓
渠道图片    到达首感     复购/传播
  ↓           ↓           ↓
必须一致   不能低于预期  必须有具体记忆锚点

闭环断裂诊断：
  断在"预期=体验"：图片比实物美 → 差评风险，预订转化率不可持续
  断在"体验=记忆"：体验不错但说不出记忆点 → 流量不可持续
  断在"记忆=传播"：记得但不推荐 → 口碑传播断路
```

## 四、第四追问：凭什么他还会回来？

> **目的：** 建立"复购/回流"的具体驱动机制

### 追问链

```
第一次可以靠吸引，第二次凭什么？
  ↓
他记得的是什么？
  → 记忆锚点是一个具体的感知时刻，还是模糊的"整体氛围"？
  → 能说出来的记忆，还是说不出来但回头的理由？

他带朋友来，用的是什么理由？
  → 这个理由是关于空间的描述，还是关于体验的邀请？
  → 朋友听了这个理由，愿意来吗？为什么？

朋友来了，他们的第一次体验和带他来的人的体验，有什么不同？
  → 熟客视角 vs 新客视角，空间能否同时满足？
```

### 系统追问话术

```
Q4-1 他上次来，离开时心里想的是什么？（不是说的，是想的）
Q4-2 他下次想来，是因为想再体验什么，还是因为带别人来有面子？
Q4-3 如果他要向朋友介绍这里，他会说几个字？那几个字是什么？
Q4-4 他的"回头理由"，有多少是设计能创造的，有多少是运营/产品/服务创造的？
```

## 五、第五追问：触底——人性基础

> **目的：** 找到消费行为背后最底层的人性动机，这是设计服务的真正对象
> **同步调用：** `用户需求层级框架.md` — 识别动机属于哪个需求层级，诊断层级覆盖盲区

### 人性基础定位：横向（动机类型）× 纵向（需求层级）

追问到底层动机后，系统需要完成两个定位：

```
横向定位（动机类型）— 这个人的驱动力属于哪一类：
  ① 安全感：被保护、被控制、不被评判、可预期
  ② 尊严感：被重视、有面子、在同伴面前重要
  ③ 归属感：属于某个群体、被人认识、有我的位置
  ④ 愉悦感：感官享受、好玩、惊喜、放松
  ⑤ 身份认同：这次消费表达了"我是什么样的人"

纵向定位（层级深度）— 这个需求在哪个满足层级：
  层级一 基础安全层（最易被遗忘，缺失则全盘失效）
  层级二 舒适功能层（行为顺畅，用户不称赞但会投诉）
  层级三 审美认同层（行业过度竞争区，差异化极难）
  层级四 社交身份层（溢价主要来源）
  层级五 意义超越层（最稀缺，最强传播力，最难复制）
```

> 详见：`用户需求层级框架.md`
> 重点：层级一（基础安全）和层级五（意义超越）是设计行业的系统性盲区，也是最大的差异化机会

### 追问到底的方式

**"为什么"连问五次（5 Whys）**

```
他为什么来这里？
  → 因为这里的氛围好
他为什么觉得氛围好？
  → 因为灯光很暖，不会让他觉得尴尬
他为什么在意"不尴尬"？
  → 因为他要带客户，客户的感受很重要
他为什么在意客户的感受？
  → 因为这顿饭要谈一个合作，他希望对方觉得他有品味
他为什么希望对方觉得他有品味？
  → 【终止】触到"尊严感"——他要在合作对象面前是"有品味的人"
```

```
→ 设计的真正任务：让这里成为"有品味的人会来的地方"
→ 具体动作：进门气场 / 灯光控制 / 服务话术 / 能被谈论的细节
```

### 系统追问话术

```
Q5-1 他这次消费，说到底是为了让自己感觉什么？
Q5-2 如果他回家后和家人说起这次，他最想说的一句话是什么？
Q5-3 这次消费，在他对自己的认知里，支撑了"我是什么样的人"这个判断吗？
Q5-4 如果把你这里所有的视觉和材质都去掉，只留下"感受"，
      那个感受是什么？这个感受是设计创造的，还是别的什么创造的？
```

## 六、追问 → 设计决策转化路径

**追问的最终目的不是了解，而是转化。** 每一层追问的答案，必须能转化为具体的设计动作。

### 转化格式（系统必须执行）

```
【追问层级】第___层（谁给钱/为何选/心甘情愿/回头/人性基础）
【追问结论】___（追问追到的底层原因）
【人性基础】___（触到的是哪个基础动机）
【设计任务】___（空间设计必须服务的具体目标）
【具体动作】___（可落地的设计决策，可检验）
【失效条件】___（什么情况下这个动作失效）
```

### 示例（精品民宿·溢价型）

```
【追问层级】第五层（人性基础）
【追问结论】他选这家民宿，是因为"这是有品位的人会住的地方"——他要在朋友圈里
            表达自己是这样的人，同时也要在与伴侣的旅行中体现他的"眼光"
【人性基础】尊严感 + 身份认同
【设计任务】让"住在这里"这件事本身，成为一种身份表达——
            出片感是表达工具，稀缺性是表达的说服力
【具体动作】①入口框景：第一张照片就是身份宣言
            ②客房内1-2个"说不清楚但拍得好看"的细节
            ③早餐/入住仪式：让他能"讲给朋友听"的小故事
【失效条件】如果出片位被大量同质民宿复制，稀缺性消失，身份表达失效
```

## 七、追问禁区（系统识别并中断）

以下情况出现时，系统必须中断追问，要求先补充信息：

```
禁区1 — 业主不了解自己的用户
  信号："我也不太清楚谁会来"
  系统动作：暂停，要求先完成用户调研或访谈，再继续追问

禁区2 — 用户是假设的，没有真实数据支撑
  信号：所有答案都是"应该会…"或"我觉得他们会…"
  系统动作：标记为"假设性结论"，要求后续验证

禁区3 — 追问结论是"他来这里是因为我们很好"
  信号：商业逻辑是自我中心的，没有消费者视角
  系统动作：反问"如果你关门了，他去哪里"，强制切换视角

禁区4 — 终止在中间层，还没触到人性基础
  信号：停在"体验好"/"价格合适"/"位置方便"
  系统动作：继续追问"为什么这对他重要"，直到触到基础动机

禁区5 — 追问结论无法转化为设计动作
  信号："他来是因为地段好"/"他回来是因为产品本身好"
  系统动作：标注为"设计无法影响的动机"，但记录在案，
            说明"设计的任务是不破坏这个条件，而非创造它"
```

## 八、追问链总图

```
项目启动
  ↓
[第一追问] 谁给你钱？
  具体到真实的人、具体的状态、具体的消费场景
  ↓
[第二追问] 凭什么他选你？
  真实竞争场域 + 决定性选择瞬间 + 比较依据
  ↓
[第三追问] 凭什么他心甘情愿？
  预期建立 → 体验兑现 → 记忆与传播 → 价值闭环
  ↓
[第四追问] 凭什么他还会回来？
  记忆锚点 + 传播话语 + 复购机制
  ↓
[第五追问] 触底——人性基础
  安全感/尊严感/归属感/愉悦感/身份认同
  ↓
触到终止条件A（人性基础）或 终止条件B（设计末端）
  ↓
[转化] 追问结论 → 设计任务 → 具体动作 → 可检验效果
  ↓
输出：追问结论卡（供全频谱扫描P1-P9使用）
```
