## 4. 核心类型

### FloorPlanFacts

职责：

```text
记录真实图纸或人工校正中的空间事实。
```

字段重点：

```text
facts_id
session_id
source_floor_plan_ir_id
coordinate_space
scale_status
boundary
immutable_elements
flexible_elements
review_flags
```

### DesignConstraintGraph

职责：

```text
把 SPG、建筑事实、用户偏好和平台方法论编译成布局约束。
```

字段重点：

```text
graph_id
spg_id
facts_id
constraints
locked_zone_ids
preferred_objectives
```

### DesignIntent

职责：

```text
表达一个版本的策略身份。
```

字段重点：

```text
intent_id
title
strategy
primary_axis
spatial_priorities
accepted_tradeoffs
source_experts
rationale
```

### LayoutIR

职责：

```text
表达生成后的布局方案。
```

字段重点：

```text
layout_id
based_on_facts_id
based_on_spg_version
design_intent_id
strategy
spaces
circulation
open_boundaries
closed_boundaries
score
risks
explanation
```

### LayoutVariant

职责：

```text
一个可展示、可比较、可选择的候选版本。
```

字段重点：

```text
variant_id
name
intent
layout
status
comparison_summary
```

### LayoutVersionGraph

职责：

```text
记录用户如何选择、修改、否定和冻结版本。
```

字段重点：

```text
graph_id
nodes
selected_version_id
frozen_version_id
rejected_reasons
```

## 5. 当前前端映射

后端 `LayoutVariant` 映射为前端 `PlanStrategy`：

```text
id = variant.variant_id
title = variant.name
summary = comparison_summary / explanation / primary_axis
tradeoff = accepted_tradeoffs[0] / risks[0]
score = layout.score.project_fit
```

后端 `LayoutIR.spaces` 映射为图纸覆盖层：

```text
x, y, w, h 使用 0-1 归一化坐标
在 SVG viewBox 1000x1000 内渲染为半透明空间块
```
