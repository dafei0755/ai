# C1 — 跨领域视角激活器

> **组别**：C 组（框架扩展·条件触发）| **阶段**：S2 | **类型**：互动·条件触发
> **原始编号**：L2 透镜激活 | **触发阈值**：relevance_score ≥ 0.6

---

## 一分钟定义

用**非设计领域的思维框架**重新解构项目问题，专门打破「在设计领域内绕圈子」的思维定势，引出不一样的问题。

---

## 功能详述

C1 激活后，从以下「透镜库」中选取 2~3 个与项目最相关的视角：

| 透镜领域 | 解构方式 | 典型问题 |
|---------|---------|---------|
| 剧场理论 | 空间 = 舞台，人 = 演员 | 这个空间里谁是「表演者」，谁是「观众」？ |
| 生态学 | 空间 = 生态系统，功能 = 物种 | 哪些功能是「关键物种」——去掉它整个系统崩溃？ |
| 行为经济学 | 空间设计 = 选择架构 | 默认布局会引导人们做出什么选择？ |
| 神经科学 | 空间 = 刺激环境 | 哪些感知刺激会影响使用者的情绪状态？ |
| 人类学 | 空间 = 仪式场所 | 这个空间会催生什么日常仪式？ |
| 系统论 | 空间 = 复杂系统 | 哪个节点的改变会引发连锁反应？ |

**C1 的价值**：不是带来「答案」，而是带来「不一样的问题」。好的跨领域视角会让用户发现「这个问题我从来没这么想过」，从而丰富 S4 的决策维度。

---

## 输入

```
jtbd_statement       # B1 任务定义（决定哪些透镜最相关）
conflict_pairs       # B2 冲突对（冲突点是透镜选择的重点参考）
relevance_score_C1   # insight_distiller 计算的相关性分
```

---

## 输出

```python
lens_perspectives: [
    {
        "lens":       "剧场理论",
        "reframe":    "这个客厅是全家人聚集的剧场，妈妈是导演...",
        "key_questions": ["谁是这个空间的主角？", "哪个角落是backstage？"]
    },
    ...
]
```

---

## 激活条件

insight_distiller 计算 `relevance_score(C1) ≥ 0.6` 时触发。

**主要触发信号**：
- 项目有跨学科属性（教育/医疗/社区空间等）
- B1/B2 的问题框架过于常规，F3 输出洞见多样性低
- 项目类型在「特殊使用场景」中（展览/零售/创意空间）

**不触发的情况**：标准住宅翻新、常规办公室改造——这类项目跨领域重构的价值低，不强制触发。

---

## 执行方式

- **透镜选择**：LLM 根据项目特征从透镜库中选 2~3 个，不随机选
- **G1 检查**：跨领域问题必须具体可落地，不接受「哲学式空洞发问」

---

## 用户交互

**有**。展示格式：

```
换一个视角看这个项目，或许能发现不同维度：

[透镜 1]：如果把这个空间当作 [X]，会问什么不同的问题？
  → [具体问题 1]
  → [具体问题 2]

这些视角有没有触发你什么新的想法？
```

---

## 协作关系

```
上游（依赖）：
  ← B1 任务目标提炼器
  ← B2 目标冲突诊断器
  ← insight_distiller（relevance_score 计算）

下游（供给）：
  → S4 张力冻结（透镜引出的问题可能成为决策维度的补充）
  → S4 任务书（被用户认可的视角写入「空间命题解释 / 设计理念基础」）
```

---

## 常见误用

1. **用太多透镜，场面失控**
   纠偏：最多 2~3 个透镜，每个给 1~2 个具体问题，不是知识展示，是思维打开工具

2. **强制触发 C1，不管项目类型**
   纠偏：标准住宅翻新用剧场理论重构价值很低，relevance_score 机制就是防止这种情况

---

## 扩展优化方向

- **透镜库扩展**：增加更多领域（博物馆学/游戏设计/仪式研究等），并按项目类型分组
- **透镜效果追踪**：追踪哪类透镜被用户「认为有用」vs「感到困惑」，持续淘汰低效透镜
