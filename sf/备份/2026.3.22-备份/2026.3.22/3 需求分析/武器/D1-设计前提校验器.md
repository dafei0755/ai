## 一分钟定义

**主动挑战 S2 分析所依赖的关键假设**，代入「最容易出问题的情形」进行对抗性检验，防止整个分析框架建立在未被验证的前提上。这是 S3 的主将，也是系统中唯一以「怀疑者」身份发声的武器。

---

## 功能详述

D1 执行两层工作：

**第一层（后台·不可见）：L9 四方对抗**

AI 内部扮演 4 种视角，对 S2 的结论进行对抗：

| 视角 | 立场 | 主攻方向 |
|------|------|---------|
| **保守方** | 风险厌恶 | 「按部就班，这个方向最容易出什么问题？」 |
| **激进方** | 颠覆性挑战 | 「如果把所有假设推翻，最差情况是什么？」 |
| **外行方** | 没有专业滤镜 | 「第一次接触此类项目的人会问什么？」 |
| **专家方** | 行业经验 | 「行业中最常出错的假设是什么？」 |

四方对抗后**收敛为 1~2 个核心挑战问**——用户只看到收敛结论，不看到对抗过程。

**第二层（展示·用户可见）：核心挑战展示**

把「最脆弱的假设」以具体问题形式展示给用户，并给出「若假设被打破，方向会怎么变」。

## 输入

```
problem_framework      # S2 全量输出（B1/B2/B3/B4/C组的结论）
conflict_pairs         # B2 冲突对
system_impact_notes    # B3 影响注记
```

---

## 输出

```python
challenged_assumptions: [
    {
        "assumption":    "业主将长期居住于此",
        "challenge":     "若 5 年内出租或出售，则极简定制化设计会严重损失租售吸引力",
        "impact":        "high",
        "alternative":   "保留主结构中性，仅在软装层面定制化",
        "user_response": None   # 用户响应后填写
    },
    ...
]
# 写入 state.challenged_assumptions
```

---

## 激活条件

- S3 启动时第一件执行，强制
- S2 全部槽位 responded 后才进入 S3

---

## 执行方式

- **执行器**：LLM 调用（四方对抗 + 收敛）
- **内部 L9 执行**：以 system_prompt 切换角色，四次内部对话后合并
- **数量约束**：对用户只展示 1~2 个最核心的挑战，不是「把所有假设都列出来批判」
- **G1 检查**：挑战问必须可证伪（「你真的会长期住吗？」vs「设计风险」——前者可验证，后者无法验证）

---

## 用户交互

**有**。展示格式：

```
在推进之前，我想挑战一个前提：

当前分析假设了：[假设内容]

但如果这个假设是错的——[具体情境]
那么方向就需要调整为：[备选路径]

这个假设成立吗？还是需要调整？
```

**用户响应类型及处理**：

| 响应类型 | 处理方式 |
|---------|---------|
| 「假设成立」 | 槽位 responded，假设被验证，继续 D2 |
| 「假设不成立」 | 记录新信息，更新 problem_framework，可能触发小范围 reframe |
| 「部分成立」 | 记录条件性承认，在未来决策中带条件标注 |

---

## 协作关系

```
上游（依赖）：
  ← S2 全量输出（B1/B2/B3 结论）

下游（供给）：
  → D2 约束条件识别器（D1 发现的「若假设不成立的备选路径」可能暗示新约束）
  → S4 张力冻结（D1 验证的假设注入决策矩阵作为「已验证前提」列）
  → state.reasoning_trace（D1 的对抗过程写入可审计轨迹）
```

---

## 常见误用

1. **展示全部对抗过程，信息量暴增**
   纠偏：用户只看到收敛之后的「1~2 个核心挑战」——四方对抗是内部机制，绝不对用户展开

2. **把「挑战一切」当成 D1 的目标**
   纠偏：D1 只挑战「最脆弱」的假设，不是系统性否定 S2 的结论；目标是「加固框架」而非「推翻框架」

3. **D1 和 D2 合并为一次交互**
   纠偏：D1 挑战假设（认知层），D2 确认约束（行动层），两件武器职责不同，必须分开执行

---

## 扩展优化方向

- **假设脆弱度评分**：对每个假设打「被打破的概率」和「被打破后的影响」两个维度的分，自动排序最值得挑战的
- **行业假设库**：按项目类型预置「最常被打破的假设」，D1 可快速定位，提升诊断质量
- **对抗视角定制化**：根据项目类型（住宅/商业/公共）切换最有价值的对抗视角组合
