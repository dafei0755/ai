# F4 — 复杂度过滤器

> **组别**：F 组（后台引擎）| **阶段**：全程 | **类型**：后台·B/D 组每次输出后运行
> **原始编号**：L5.R 奥卡姆检验

---

## 一分钟定义

每次 B 组或 D 组武器产生输出后，**检测并删除冗余结论**，保证展示给用户的内容是精炼的核心，不是「堆砌以显示分析深度」。

---

## 功能详述

F4 的核心规则（奥卡姆剃刀：如无必要，勿增实体）：

| 检查项 | 不通过的例子 | 处理方式 |
|-------|---------|---------|
| **重复表达** | 同一个意思在输出中出现两次 | 合并为一条 |
| **废话结论** | 「这个项目的核心是满足用户需求」 | 删除 |
| **过度枚举** | 列出 8 个冲突对（远超用户能处理的） | 保留最高影响的 3 个 |
| **不可执行的结论** | 「应该注重整体感」 | 标记为不够具体，请求 G1 介入 |

---

## 输入

```
weapon_output   # 任意 B/D 组武器的原始输出
```

---

## 输出

```
filtered_output   # 过滤后的输出（结构不变，内容精简）
```

---

## 激活条件

所有 B 组（B1/B2/B3）和 D 组（D1/D2）在**展示给用户之前**自动触发 F4 → F5 → G1 三层过滤。

---

## 用户交互

**无**。用户感知不到 F4 存在，只感受到「AI 说人话，没有废话」。

---

## 协作关系

```
上游（依赖）：← B/D 组武器原始输出
下游（供给）：→ F5 套话替换过滤器（F4 先删冗余，F5 再换套话）
```

---

## 扩展优化方向
