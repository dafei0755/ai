# F8 — 下游专家问题生成器

> **导航提示：** 建议先读 [README](README.md) 与 [03-后台分析与质量门控武器](03-后台分析与质量门控武器-2026-03-11.md)；本文属于 S4 前最关键的交接编译型后台武器。

> **组别**：F 组（后台引擎）| **阶段**：S4 前 | **类型**：后台·S3 冻结后
> **原始编号**：M23 专家交接叩问 | **消费方**：project_director

---

## 一分钟定义

根据需求分析全量输出，**为每个即将接手的专家角色生成最关键的交接问题集**，把「需求分析阶段发现的核心不确定性」转化为专家开始工作前必须回答的问题清单。

---

## 功能详述

F8 专门服务于「需求分析 → 专家执行」的交接界面：

| F8 生成的问题类型 | 举例 |
|----------------|------|
| **假设验证问** | 「我们假设业主将长期居住，请确认租售计划对方案的影响」 |
| **冲突处理问** | 「客厅开放性 vs 工作区隔音已冻结为『工作区优先』，你的方案如何在视觉上保留开放感？」 |
| **约束确认问** | 「预算 60 万硬限，你的选材方案是否在此范围内？」 |
| **深度探索问** | 「用户是『展示者』模式，入口视觉焦点如何强化？」 |

F8 生成的问题**不向用户展示**，而是注入 project_director 的专家调度模块，作为专家开始工作前的前置检查清单。

---

## 输入

```
problem_framework       # 完整问题框架（S2 收口）
confirmed_constraints   # D2 完整约束清单
tension_decisions       # S4 冻结的决策
gap_answers             # E1 补全结果
identity_mode           # B4 识别结果
behavior_mode_profile   # C3 识别结果（若有）
```

---

## 输出

```python
expert_handoff_questions: {
    "spatial_designer": [
        "工作区隔音与客厅开放感如何平衡？",
        "入口仪式感如何在 3.5m 层高条件下实现？"
    ],
    "material_advisor": [
        "预算 60 万内，哪些材料可支撑展示者身份需求？",
        "孩子哮喘约束下，哪些材料需要排除？"
    ],
    "lighting_designer": [
        "多功能流动使用模式下，照明分区如何支持快速切换？"
    ]
}
```

---

## 激活条件

S3 冻结候选形成后，且 feasibility 结果允许继续时，在 S4 确认任务书前后台自动运行。

---

## 用户交互

**无**。消费方是 project_director，不是用户。

---

## 协作关系

```
上游（依赖）：← 全量 S1~S3 输出 + feasibility 反馈
下游（供给）：→ project_director（专家调度时参考，专家开始前必须回答）
```

---

## 常见误用

把 F8 问题展示给用户（增加认知负担，且这些问题是给专家的，用户回答不了）。

---

## 扩展优化方向

- **专家能力-问题匹配**：根据注册专家的能力标签，自动过滤掉不相关的交接问题
