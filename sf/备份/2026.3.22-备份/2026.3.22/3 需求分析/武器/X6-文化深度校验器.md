# X6 — 文化深度校验器

> **组别**：X 组（场景扩展·新增）| **阶段**：S3（D1 挑战后）/ S4 前 | **类型**：后台·文化质量门控
> **优先级**：P2 | **触发**：项目含文化转译需求时 | **消费方**：F3、G1（补充的门控维度）

---

## 一分钟定义

**检测设计方向中的文化转译是否停留在符号/视觉层，还是真正抵达了价值观/精神层**。专门防止「符号化浅层文化表达」——这是设计行业中最常见的失败模式之一。

---

## 功能详述

「符号化浅层表达」的核心特征：设计只借用了文化的外在视觉符号（造型/颜色/装饰图案），没有触及文化的内在精神结构（价值观/仪式/时间观/空间观）。

题集中「避免……的浅层表达」的明确要求出现在：
Q2（厚度感）、Q5（Tiffany 精神）、Q17（书法气质）、Q37（维吾尔族几何）、Q43（盛唐文脉）、Q52（昆曲慢美学）、Q54（延安精神）、Q66（文化根源链接）……

X6 提供一套**内外层校验机制**。

### 两层校验模型

**Layer 1：符号层诊断**  
检测输出中「纯视觉符号引用」的比例：

| 风险信号 | 举例 |
|---------|-----|
| 直接使用文化符号装饰 | 「引入书法字作为装饰背景」 |
| 颜色=文化等号 | 「大量使用 Tiffany 蓝营造品牌感」 |
| 图案化移植 | 「使用民族几何纹样作为墙面肌理」 |
| 标签式文化 | 「融入中式元素」「体现禅意」 |

**Layer 2：精神层验证**  
检测输出是否触及文化的价值观核心：

| 文化类型 | 精神层核心问题 |
|---------|------------|
| 书法文化 | 书法的「时间性」（笔的运动/停顿/力道的时间痕迹）如何在空间中被表达？ |
| 文人精神 | 「退藏于密」的主动留白，vs「简洁」的被动减法——是哪一种？ |
| Tiffany 精神 | 被珍视感的来源是「精致细节对待自己的仪式感」，不是蓝色盒子 |
| 延安精神 | 土窑洞的质朴不是贫穷，而是「与目标相比，物质是次要的」的意志主义 |
| 昆曲慢美学 | 「慢」不是节奏缓，是「每一个时刻都有完整的意义」的时间密度 |

### 校验输出：3 级结论

```
PASS（深度转译）：方向抵达精神层，可继续
WARN（停在美学层）：已有美学转译，但缺乏价值观依据，需补充
FAIL（纯符号层）：拦截，触发 F3 重新提炼
```

## 输入

```
design_direction_draft  # 当前已输出的设计方向（F3 关键洞见 + B1 框架）
cultural_reference      # 项目中明确提及的文化参照
project_type            # 文化机构/品牌/个人项目（影响深度要求）
```

---

## 激活条件

检测到以下任一：
- 项目 brief 包含文化类型关键词（书法/水墨/文人/民族/传统/地域/在地/历史/精神地标）
- X4 已激活（品牌旗舰含文化属性）
- B1 的 JTBD 中「文化传承」被识别为核心动机

---

## 执行方式

- LLM 主导（语义理解：区分「符号引用」和「精神转译」）
- WARN 级别时：不中断流程，向 F3 传递「精神层待补充」的指令
- FAIL 级别时：拦截，强制触发 F3 重新提炼洞见

---

## 用户交互

**无（PASS/WARN 时）**。  
**有（FAIL 时，最多 1 个问题）**，用以引导客户揭示文化意图的精神核心：

> 「您提到书法大酒店——请问您认为书法最珍贵的不是字形，而是什么？」

---

## 协作关系

```
上游（依赖）：← F3 关键洞见输出 ← B1 问题框架 ← X4（如有品牌文化属性）
下游（供给）：→ F3（WARN/FAIL 时触发重新提炼）
             → G1（X6 的 FAIL 等同于 G1 的 "contradictory" 拦截）
             → F9（文化约束类的「不可突破边界」应引用 X6 精神层分析）
```

---

## 常见误用

1. 对无文化转译需求的项目运行 X6（住宅纯风格偏好项目不触发）
2. 把「风格一致」和「文化深度」混淆——风格一致是 G1 的事，文化深度是 X6 的事

---

## 扩展优化方向

- **文化精神层知识库**：为高频文化类型（书法/文人园林/禅宗/昆曲/民族几何/延安精神）建立「精神核心问题集」，X6 的校验速度和准确度均可大幅提升
