# Z4 — 公众接受度与社会摩擦预测器

> **组别**：Z 组（城市底盘·新增）| **阶段**：S3/S4 | **类型**：后台·社会反馈预判器
> **优先级**：P1 | **触发条件**：更新、社区、公共服务、城市示范类项目 | **消费方**：Y2、Y3、Y4

---

## 一分钟定义

提前预测项目在公众、居民、商户、使用者中可能引发的**接受度波动与社会摩擦点**，防止方案在专家视角完美、在真实社会运行中翻车。

---

## 功能详述

城市与公共项目的失败，很多都不是专业失败，而是社会反馈失败：
- 居民觉得被打扰
- 商户觉得被替换
- 年轻客群来了，但本地人不再使用
- 运营叙事和公众感受不一致

Z4 关注的是“社会摩擦”。

### 四类摩擦

| 类型 | 典型问题 | 输出 |
|-----|---------|------|
| **生活摩擦** | 原有日常便利被打断了吗？ | `life_friction` |
| **身份摩擦** | 原居民是否觉得自己被边缘化？ | `identity_friction` |
| **价格摩擦** | 租金/消费门槛是否挤出原用户？ | `price_friction` |
| **叙事摩擦** | 官方叙事和真实体验是否脱节？ | `narrative_friction` |

### 典型输出

```python
social_friction_forecast: {
    "life_friction": ["夜经济引入后，老年居民晚间通行舒适度下降"],
    "identity_friction": ["原居民可能认为街区被包装给游客看，而不再属于自己"],
    "price_friction": ["非标品牌租金承受能力高，可能抬升原底商退出风险"],
    "narrative_friction": ["宣传中强调社区共享，实际体验更像消费型打卡街区"],
    "acceptance_guardrails": [
        "保留高频民生服务比例",
        "夜间声光边界前置限制",
        "设置原居民优先使用场景"
    ]
}
```

## 激活条件

- 项目涉及社区、居民、老城、乡村、公共服务、更新示范
- 或项目存在显著“对外展示”与“本地日常”双重目标

---

## 用户交互

**有（最多 1 个问题）**。  
用于探测可接受边界：

> 「如果项目最成功的一面，是吸引大量外来访客；那您最担心本地居民会失去什么？」

---

## 协作关系

```
上游（依赖）：← Y2 治理网络 ← Z1 政策目标树
下游（供给）：→ Y3（社会摩擦本身是关键风险假设来源）
             → S4（冻结社会边界与接受度红线）
             → Y4（把 acceptance_guardrails 转成推进边界）
```

---

## 常见误用

1. 把 Z4 当作舆情工具（它预测的是使用摩擦，不只是网络评价）
2. 只预测反对，不预测接受度提升的条件（guardrails 同样重要）
