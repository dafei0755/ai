# 方案高参能为你做什么？

## 核心定位（重新定义）

**方案高参不是"设计思路提供方"，而是"项目决策体系的建立与管理者"**——我们帮你把一个模糊、多维、充满冲突的问题，转化成结构化的工作体系，然后用明确的任务清单、责任分工和执行节奏去推进它。

---

## 我们实际在做的9类深层工作

### 1⃣ 问题结构化与决策框架建立

**你的问题**："这个项目太复杂，多个诉求互相打架，不知道先做什么"

我们做的事：
- 把模糊的用户输入转化成结构化的决策问题
- 识别有效决策变量与无效变量（什么因素真的重要，什么是噪音）
- 发现隐性的冲突点、约束条件、优先级顺序
- 产出"冻结的基线卡"，后续所有工作都对标这张卡

**真实案例**：
- 豪宅项目中"奢华感vs克制品味"的冲突，怎样重新定义问题使其变成"统一的美学表达"而不是"选择题"
- 多代同堂家庭的"老人需求 vs 年轻人审美"，怎样在问题层就找到共同目标（家庭互动价值）而非空间层纠缠

---

### 2⃣ 目标人群与使用场景的深度研究

**你的问题**："这个空间谁来用？他们的真实需求是什么，而不是他们说的需求？"

我们做的事：
- 从业主身份、消费人群、生活方式建立精准人物模型
- 识别关键行为节点与情绪峰谷（什么时刻最满意，什么时刻最失望）
- 预测空间使用的实际路径与潜在冲突点
- 把"度假旅程"还原成可设计的时间序列，识别每个时间点的空间需求

**真实案例**（从100个模拟问题抽样）：
- 题号4：轻度假民宿的实际旅程拆解（第一晚的期待值vs第三晚的真实行为）
- 题号33：25㎡出租屋的"居住+工作+会客"三态切换（用户的心理负荷在哪）
- 题号79：精品咖啡店的"18分钟停留时限"——怎样通过空间让用户舒适而不冗长

### 3⃣ 跨学科知识融合与转译

**你的问题**："我想融入艺术启发/建筑大师方法/商业体系，但怎样才不显得生硬"

我们做的事：
- 从艺术、历史、商业、心理学、人类学等领域提炼设计启发
- 分析这些启发的"底层逻辑"（为什么管用，不只是"它们长什么样"）
- 将抽象概念转化为可操作的空间决策变量
- 避免"符号堆砌"，确保融合的深度与可落地性

**真实案例**（从100个模拟问题抽样）：
- 题号14：劳斯莱斯定制体系→设计流程（从"客户访谈逻辑+材料定制系统+专属符号"反推项目方法论）
- 题号21：国际顶级建筑事务所→中国设计公司能力升级路径（Gensler的多线程协作方法如何转译）
- 题号34：诗人意象"月亮落在结冰的湖面上"→空间实现（光影+材料+比例的诗性转译）
- 题号17：书法精神→酒店空间系统（怎样让"书法的笔触与节奏"变成建筑的空间逻辑）

### 4⃣ 约束条件下的方案优化与成本精准分配

**你的问题**："预算砍了50%，怎样保证不掉价？"

我们做的事：
- 建立"视觉杠杆"理论——用相同资源制造更高品质感
- 明确"哪3个地方必须重金投入"和"哪3个地方可以极致压缩"
- 在极限环境（高原、海边、山洞）、极限成本（8000元、3000元/㎡）、极限时间下找到品质突破口
- 确保每一分钱都被用在关键的感知点上

**真实案例**（从100个模拟问题抽样）：
- 题号77：50万老房翻新，预算严格控制，如何用"灯光+视觉焦点+留白"制造杂志级效果
- 题号78：300㎡豪宅仅3000元/㎡，怎样保持"豪宅的体面感"而非掉成出租屋感
- 题号85、86：西藏高山/三亚海边的极端环境，材料成本高、工期短，怎样破局

### 5⃣ 多元诉求的平衡与冲突调节

**你的问题**："这个空间里有三个人，每个人的审美和需求都不一样，怎样都能满足"

我们做的事：
- 找到多个诉求背后的"共同价值观"（不是妥协，而是升维）
- 设计"可分可合、可切可转"的灵活场景
- 识别冲突点、评估冲突程度、提出调节方案（什么该让步，什么不该让步）
- 通过空间结构而不是装饰让多元共存变成一种和谐

**真实案例**（从100个模拟问题抽样）：
- 题号31：父亲红木中式+母亲北欧明亮，如何在"材料语言+空间比例+色彩过渡"中实现融合，而不是"你一间我一间"
- 题号50：再婚家庭，两个无血缘且处于不同青春期的孩子，怎样既有公共交流区又有绝对隐私
- 题号41：三个女性合租大平层（律师+插画师+教练），如何设计"共享社交+三套独立套房"的分层逻辑

### 6⃣ 商业运营与空间体验的耦合设计

**你的问题**："这个空间怎样帮我赚钱？不仅要漂亮，更要有转化力"

- 让空间设计直接服务运营KPI

**真实案例**（从100个模拟问题抽样）：

### 7⃣ 技术复杂性下的隐形系统整合

## 工作逻辑链路：从问题到执行

### 阶段1：**问题界定** （冻结"对齐简报"）
- Input：用户的模糊表述、期望、限制条件
- Process：**T1 信息对齐** → 结构化分析 → 决策变量识别 → 边界确认
- Output：基础信息卡 + 项目目的 + 交付物清单 + 成功判定 + 边界 + 待确认项
- 关键产出物：**AlignedBrief**（对齐简报，用户必须确认）

### 阶段2：**决策体系建立** （冻结"初步设计包"）
- Input：已确认的对齐简报
- Process：
  - **3.S.1 解题思路**：为什么这道题这么难、难点在哪、需要什么样的能力
  - **3.S.2 工作地图**：什么工作必须做（A类交付驱动 + B类洞察补位）
  - **T2 梦幻团队组建**：每个角色都对应工作地图中的明确工作责任
  - **T3 任务安排**：工作地图编译成具体任务清单（含顺序、依赖、门禁）
- Output：完整的任务清单 + 梦幻团队 + 执行节奏
- 关键产出物：**InitialDesignPack**（初步设计包，包含全部约束、判断、任务）

### 阶段3：**深化与反馈** （持续迭代）
- Input：已冻结的约束、已有判断、新的细化诉求
- Process：**T4-T5** → R0-R5 回合制 → 跨学科融合刷新 → 冲突调节 → 冲突调整
- Output：可交付的设计方向与策略建议
- 关键产出物：**DeliveryBundle**（完整交付物包）

## 人员角色与职责分工

### 什么是"梦幻团队"

**梦幻团队不是标准配置，而是根据每个项目的"工作地图"动态组建**。

从HAY民宿案例看，组建逻辑是：
1. **先生成"解题思路"**：这道题的核心难点在哪，需要什么样的思维方式
2. **再生成"工作地图"**：
   - A类工作：直接对应交付物的研究与判断任务
   - B类工作：项目自带、但用户没显式提出的背景研究
3. **最后才是"梦幻团队"**：每个角色都必须能回溯到工作地图中的明确工作项

**结果是**：不同的项目，团队组成完全不同。HAY案例需要14个角色，但一个极简家居项目可能只需要6个角色。

### AI分工（方案高参）

✅ **方案高参负责**：
- 问题结构化、决策框架构建
- 文献研究、背景分析、观点综合
- 工作地图生成、任务编排、逻辑验证
- 跨学科思路融合、启发转译
- 冲突识别与调节建议
- 风险预警与回退条件定义

### 梦幻团队分工（人类专家）

✅ **梦幻团队负责**：
- 定性判断、品味决策、价值观表达（"这个方向对不对"）
- 现场实地研究、与相关方的访谈（收集一手数据）
- 定性或定量分析中的经验分析
- 图纸、模型、效果呈现（可视化交付）
- 与甲方的深度互动、说服演讲

### 协作环节

🤝 **AI + 梦幻团队共同做**：
- 用户反诘与需求澄清（用户可能说得不清楚，需要双向对话）
- 方案评估与比对（人类提多个候选方案，AI做系统分析与冲突检验）
- 决策冲突处理（AI识别冲突，人类做价值判断）
- 沟通文案与演讲稿（AI整理逻辑框架，人类调整话术与表达）

## 我们的能力边界（最终版）

### ✅ 我们做的工作

| 维度 | 具体内容 |
|------|---------|
| **概念框架** | 整体定位、精神气质、决策思路、执行约束、风险预警 |
| **决策体系** | 工作地图、任务分解、责任落位、依赖分析、门禁条件 |
| **多学科融合** | 从建筑、景观、室内、美学、心理学、人文、经济学等全维度综合 |
| **策略论证** | 为什么这个方案、对标分析、成本分配、商业价值 |
| **前置把控** | 虽然不做工程细节，但在概念阶段会考虑结构、成本、规范、施工的**可实现性约束** |

### ❌ 我们不做的工作

| 类别 | 具体内容 |
|------|---------|
| **具体实施** | 施工图深化、现场指挥、工程管理 |
| **工程设计** | 结构计算、建筑施工图、景观工程图纸 |
| **专业系统** | 暖通、水电、弱电、消防等系统的工程设计 |
| **严格成本管理** | 预算控制、招标采购、造价审核（但会给出成本分配逻辑） |
| **项目管理** | 进度表、施工协调、现场质量管理 |
| **渲染出图** | 3D 建模、效果图渲染（这是可视化设计师的事） |
