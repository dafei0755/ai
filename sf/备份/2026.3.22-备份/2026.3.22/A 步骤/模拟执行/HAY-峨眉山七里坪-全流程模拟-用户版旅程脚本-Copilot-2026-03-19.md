### 3.S.1 解题思路的方法论（第一性原理反推版）

> 这一段是本示范的“方法论中枢”：不是先给方案，而是先从终局目标反推当前动作。

**步骤 M0｜方法论前置审阅门（开局先过）**

- 目标：在进入团队组建与任务编排前，先判断“题是否被想对”。
- 原则：**先把方法论站稳，再进入执行链**；不允许“边做边纠偏”成为常态。
- 审阅门问题（开局即判）：
  1) 是否已明确终局目标（不是风格偏好，而是项目成功定义）？
  2) 是否已定义成功条件（可检验、可签收）？
  3) 是否已识别关键变量与关键约束（决定成败的少数项）？
  4) 是否已明确失败前置清单（最可能失败点）？
  5) 是否已得到最小关键动作顺序（先后不可颠倒）？
- 判定规则：
  - 任一项为“否” → 不进入 T2/T3，先回到信息对齐补齐；
  - 全部为“是” → 才进入工作地图、团队组建与任务编排。

一句话：**方法论审阅不是收尾检查，而是开局门禁。**

**步骤 M1｜定义终局目标（End State）**

- 这项目最终要赢在哪里？
- 在本案里：**终局是业主盈利**，品牌与空间只是盈利系统的一部分。
- 终局拆解为“用户买单链条”：
  - **买单前**：用户怎么知道项目、为什么选这家；
  - **买单中**：到达感/等候/付款/入住是否顺滑并支撑成交；
  - **买单后**：体验与性价比反馈是否驱动复购与传播。

**洞穿：为什么必须这样做（盈利项目因果链）**

- 因为商业项目的终局不是“方案通过”，而是“持续盈利”；
- 盈利不是单点结果，而是链条结果：
  1) **动机成立**：用户为什么要出发、为什么要花这笔钱；
  2) **感知成立**：用户是否“觉得值得来、值得住、值得分享”；
  3) **比较胜出**：和同行比、和直接竞品比、和替代选择比（不出行/去别处）能否赢；
  4) **标杆启示转化**：行业标杆不是抄答案，而是提炼“可迁移机制”；
  5) **身份认同成立**：用户是否把“来这里”视为自我表达与圈层认同；
  6) **原创独特性成立**：是否形成不可替代记忆点，避免被价格战同质化；
  7) **复购与传播成立**：一次交易变长期关系，形成二次增长飞轮。

一句话：**先把“为什么有人愿意持续买单”讲透，再谈空间策略；否则只有图面，没有生意。**

**三条核心驱动力模型（每个盈利项目都要有）**

> 规则：每条驱动力都必须“层层递进、环环相扣”，并能回写到任务与验收。

1) **盈利质量驱动力（业主侧）**
- 赚钱 → **有尊严的赚钱**（不是透支品牌/体验）
- 有尊严的赚钱 → **持续性的赚钱**（不是短期爆单）
- 持续性的赚钱 → **游刃有余的赚钱**（可复制、可扩张、可抗波动）
- 游刃有余的赚钱 → **不焦虑的赚钱**（现金流与风险结构健康）

2) **用户关系驱动力（用户侧）**
- 初见（被看见/被吸引）
- 相处（消费过程中的兑现体验）
- 久处（稳定满意与习惯养成）
- 久别（离开后仍有记忆与牵引）
- 重逢（复购与主动回流）

3) **交易体验驱动力（价值感侧）**
- 交易不是“支付动作”，而是“价值交换体验”；
- 设计要让交易过程可感知地变得：**文艺、美好、认同、感动、激动**；
- 顶级闭环：**消费者非常开心地让业主赚钱**——因为消费中得到了其真正想要且在别处难以获得的价值。

**方法论落地要求（防空转）**
- 每个专题策略必须标注它服务哪条驱动力、哪一层级；
- 每条驱动力都要有对应失败信号（如：低复购、低转介绍、价格敏感）；
- 任务书冻结前必须证明“三驱动力至少各有一个有效证据链”。

**步骤 M2｜定义成功条件（Success Conditions）**

- 终局目标必须可检验，否则无法执行。
- 在本案里：
  - **买单前成功条件**：获客触达有效、品牌认知清晰、竞品比较中有选择理由；
  - **买单中成功条件**：关键触点无断裂，支付与入住链路不掉转化；
  - **买单后成功条件**：满意度与性价比评价为正，复购与推荐意愿成立；
  - 同时满足：用户能感知 HAY 方法语法（不是贴皮）、山地场景不冲突、运营三年可持续。

**步骤 M3｜识别关键变量（Key Variables）**

- 找“决定成败的少数变量”，而不是平铺所有信息。
- 在本案里：
  - 买单前变量：触达渠道、品牌记忆点、目的地吸引理由、定价认知；
  - 买单中变量：到达动线、等待体验、支付 friction、入住首感；
  - 买单后变量：体验兑现度、性价比感知、复购触发点、传播触发点；
  - 以及基础变量：品牌转译准确度、场地参数、成本/供应链可实现性。

**步骤 M4｜反推最小关键动作（Minimum Critical Moves）**

- 每一步都必须回答：此刻先做哪件最小但关键的事，才能降低失败概率？
- 在本案里：先锁 T1 基线 → 产出解题思路 → 生成工作地图 → 再编组团队与任务。

**步骤 M5｜建立失败前置清单（Failure-First）**

- 先问“什么会让项目失败”，再组织任务顺序。
- 在本案里：
  - 买单前失败：没人知道你，或知道但不选你；
  - 买单中失败：体验断点导致临门流失；
  - 买单后失败：觉得不值，不复购，不传播；
  - 以及基础失败：风格贴皮、在地错配、成本失控、供应链断点。

**统一工作句式（全流程通用）**

- 为了达成 **X（终局目标）**，
- 本阶段必须先锁定 **Y（关键变量/关键约束）**，
- 否则会导致 **Z（关键风险/失败后果）**。

一句话：**解题思路不是灵感描述，而是“终局→条件→变量→动作→风控”的可执行方法论。**

**盈利项目扩展句式（建议优先使用）**

- 为了实现 **盈利目标**，
- 必须先证明 **用户动机/感知/比较胜出/身份认同/原创独特性** 至少有一条主链可成立，
- 否则即使空间完成，也会陷入 **低转化、低复购、低传播**。

### T2 梦幻团队组建：3.S.1 解题思路 → 3.S.2 工作地图 → 团队清单

**系统来由旁白**：
> 在展开议题前，我先按你在 T1 确认的基线，把这轮解题思路推导出来，并先通过“方法论前置审阅门”；只有审阅门通过，系统才会生成工作地图。你要先看懂为什么这样拆题、为什么需要这些能力，再确认这支团队上不上。

**你看到（结构化两步）**：

1) **解题思路（工作地图的前置推导，系统内置）**

**这道题按第一性反推后的核心判断：**
- **终局目标**：业主盈利成立；空间与品牌服务于盈利，不反过来；
- **成功条件**：买单前可获客可选择 + 买单中可转化 + 买单后可复购可传播；
- **关键变量**：前中后买单链条变量（触达/选择、转化触点、复购传播）+ 在地与成本可实现性；
- **失败前置**：前链不来客、中链掉转化、后链无复购口碑，以及风格贴皮/参数失真/供应链断点；
- **最小关键动作顺序**：先锁定义，再排任务，再做专题，不反过来。

**基于以上推导，系统生成本轮工作地图（系统内置，不单独呈现审批），工作分两类展开：**
- **A类——交付物驱动工作**：直接对应你在 T1 确认的 5 项交付物（色彩系统 / 家具策略 / 尺度控制 / 公区组织 / 风险清单），每项都有对应的研究与判断任务；
- **B类——洞察补位工作**：项目类型自带、你没有显式提出但必须补齐的背景研究（经营成立性 / 区域约束 / 标杆边界 / 风险总控底图）。

**梦幻团队按"有明确工作责任"原则编组：**
- 每个角色必须可以回溯到工作地图中的某项具体工作；
- 没有对应工作的角色不进入清单；
- 方向锁定后可激活的角色，现阶段保留资格，按进度激活。

> 工作地图由系统依据解题思路维护，角色汇报时会按各自工作包逐条呈现；你现在只需要确认这支团队。

2) **梦幻团队清单（确认后进入）**

**空间与落地**

- **空间设计总统筹**
  - 工作内容：整体空间策略统领，划定各专题边界，协调跨角色冲突
  - 使命：让每个设计判断都可回溯到项目基线，不跑偏、不膨胀

- **实施边界顾问**
  - 工作内容：耐候选材核查、工艺可行性评估、成本上限锁定
  - 使命：守住"想法落得了地"这条红线；高湿山地环境下不留可见缺口

- **建筑-景观室内接口顾问**
  - 工作内容：室内与建筑结构、景观边界的节点对齐与协调
  - 使命：三界不断层，过渡空间体验完整，不靠室内"打补丁"救场

**用户与体验**

- **用户研究专家**
  - 工作内容：目标人群画像建立、核心行为特征与决策动机分析
  - 使命：让所有判断有真实用户作为锚点，而非依赖设计师的想象

- **轻度假旅程研究员**
  - 工作内容：周末短住旅程拆解，识别情绪峰谷，标注体验断层
  - 使命：把"住宿体验"还原为可设计的时间序列，让空间回应人的节奏

- **社交心理研究员**
  - 工作内容：公共空间社交密度、行为边界与偶遇条件研究
  - 使命：让"可见不强制"有设计依据，而不只是一句口号

**品牌与风格转译**

- **HAY 品牌研究专家**
  - 工作内容：HAY 品牌语义提炼、民宿语境转译规则制定
  - 使命：确保 HAY 是方法与语法，而非视觉贴皮；能说清"哪里像、哪里不能照搬"

- **北欧生活方式研究员**
  - 工作内容：功能主义与克制美学的日常生活化解读，提供可操作参照
  - 使命：用生活逻辑连接品牌与实际使用，防止风格流于形式

- 这份任务书是否清楚回答了“项目最终要什么”？
- 是否明确了“项目取决于什么”（关键变量/关键约束）？
- 是否把“先做什么、后做什么”写成可执行顺序？
- 是否写明“若不这样做会失败在哪里”？
- 是否保留了待确认项的触发条件与回写路径？
- 是否讲清“用户为什么来、为什么选、为什么复购、为什么传播”？
- 是否完成“同行/竞品/替代选项”比较并形成可解释胜出理由？

说明：上述项应在 3.S.1 的“方法论前置审阅门”已完成首轮校验；T5 仅做“执行后是否仍一致”的复核。

若复核出现“否”，说明执行过程中发生偏移，应回到对应阶段补齐后再冻结。

**可回溯索引（签署时可见）**：
- 每条结论附“来源阶段 / 主提角色 / 联提角色 / 用户确认轮次”；
- 可点击任一条目回看 T2/T3/T4 对应记录与裁决过程。

**你做的动作**：
- 快速审阅任务书全景；
- 对一条表述做内联微调（不改实质判断）；
- 保留待决项，并确认其状态标签与后续检查点；
- 点「确认并冻结」。

**改动边界（用户可见）**：
- **不可直接改**：核心命题与主要取舍（需回到 T4-1）；已锁定专题关键参数（需回到 T4-2）；
- **可直接改**：文字表述、待确认项状态标签、缺口优先级标注。

**系统回声**：
> 任务书已正式冻结，包含已确认项与待确认项；后续补充信息将按索引回写并通知你。是否进入方案高参，由你明确选择「继续」后再启动。

**节点切换提示（用户可见）**：
> 到这里，功能 A（设计任务书）完成。你若选择「继续」，系统才进入功能 B（方案高参）。

## 2. 方案高参（大节点4，用户选择「继续」后）

> 这一段不是“你要手动操作很多”，而是“你看得见系统在干什么、遇到什么、如何回报你”。

### 4.1~4.6 用户可见映射

| 二级步骤 | 你看到的内容 |
|---|---|
| 4.1 R0 触发判定 | 系统确认你是否明确发起「继续 / 修改 / 派生」 |
| 4.2 R1 意图归类 | 系统告诉你本轮属于“深化执行/局部修订/解释”等哪一类 |
| 4.3 R2 上下文装载 | 系统声明本轮读取 `DesignTaskBook` 与本轮意图 |
| 4.4 R3 动作编排 | 系统按当前目标生成 E1/E2/E3 动作序列 |
| 4.5 R4 执行协同与审阅 | 系统执行并进行质量检查、冲突仲裁 |
| 4.6 R5 回写收束 | 系统回写结果与风险，并给你下一步选项 |

### E1 品牌转译与行为校验

**你会看到**：
- 系统正在验证“是否变成展示化北欧风”；
- 系统正在检查“可见不强制”的社交逻辑是否成立。

**阶段结论**：
- 无展示化跑偏；
- 行为逻辑成立，可进入专题深化。

### E2 专题深化与参数化

**你会看到**：
- 色彩板样本确认（含场地色去饱和验证）；
- 家具与工艺可行性确认；
- 尺度与开口策略可行性提示；
- 公区节点脚本可落地。

**你会收到提醒**：
- 耐候材料是高风险，采购前必须复核；
- 部分成本项需在下一轮预算中明确。

### E3 交付打包

**你会拿到**：
- 色彩系统说明
- 家具语法与选配策略
- 尺度与开口规则
- 公共社交四节点组织
- 风险清单与后续验证列表

## 3. 气口机制在全过程怎么体现（用户版）

| 时刻 | 你可以做什么 | 系统会怎么回 |
|---|---|---|
| 每步提交后 | 不自动跳下一步，先停住 | 给回声 + 等待态 |
| 💬 展开聊聊这个 | 深挖当前卡片的含义/代价/案例 | 保持当前阶段，不乱跳 |
| 🔄 换个角度重新出牌 | 重设提问框架/排序/粒度 | 旧卡作废，新卡接上 |
| ❓ 你为什么这么判断 | 要证据与推理来源 | 给来源与逻辑说明 |
| ▶ 继续下一步 | 你确认推进 | 系统再出下一张卡 |

一句话：你始终拥有节奏控制权。系统辅助判断，但不替你“偷偷推进”。
