## 一、盈利模式判断入口（优先于一切分析）

### 系统必须先问的三个问题

在进入任何具体分析前，系统必须通过以下三题锁定项目的盈利模式：

**Q1 — 这个项目最主要靠什么赚钱？**
> 选项提示（辅助用户思考，不强制选一）：
> - 靠大量进店的人流 / 高翻台 / 规模触达
> - 靠有限但高客单价 / 品牌溢价 / 稀缺感
> - 靠老客回头 / 会员体系 / 私域积累
> - 靠人带人的社群连接 / 内容生态 / 圈层认同

**Q2 — 如果这个项目第一年成功，最重要的那一个指标是什么？**
> 选项提示：
> - 日均客流量 / 翻台次数
> - 平均客单价 / 溢价幅度
> - 回头客占比 / 复购率
> - 新成员增长数 / 社群活跃度

**Q3 — 你的竞争对手是谁？用户凭什么选你而不选他？**
> 系统关注：用户给出的理由是否真实可检验，还是只是愿望表达

**判定规则：**
- 三题答完 → 匹配主盈利模式（见第二章）
- 多个模式并存 → 确定主次关系（主模式决定策略骨架，次模式填充细节）
- 用户答不出 Q1/Q2 → **回到信息对齐，不进入设计阶段**

## 二、四个盈利模式（主轨）

### 2.1 流量型

**核心机制：** `量 × 转化率 × 客单价 = 收入`

命门在**前端截流**——进来的人够多，才有后续一切。

**典型业态：** 街边餐饮、快消零售、高客流咖啡、网红打卡店

**设计真杠杆（系统优先分配资源的位置）：**

| 杠杆位置 | 商业逻辑 |
|---------|---------|
| 门头 / 立面 / 橱窗 | 路过变进店的截流效率 |
| 主动线效率 | 单位时间内翻台量最大化，减少等待摩擦 |
| 峰值出片位 | 顾客成为传播媒介，带来下一批流量 |
| 等位区体验 | 将等待转化为体验，减少流失 |

**设计无效区（系统不在此处过度投入）：**
- 深处的材质细节、私密角落、空气感营造
- 过长的入口仪式感（阻碍截流效率）
- 功能过于复杂的动线（降低翻台速度）

**失败前置清单（系统在策略层之前必须确认）：**
1. 选址是否有足够自然客流？否则设计无法救盘
2. 出片位设计了吗？传播断路则流量自然衰减
3. 高峰时段动线是否测算过？拥堵 = 翻台崩塌

**三驱动力在流量型的映射：**
- 盈利质量驱动力：靠效率赚钱 → 设计要服务效率，而非阻碍效率
- 用户关系驱动力：初见即决策（相遇窗口极短）→ 门头/橱窗就是"初见"
- 交易体验驱动力：让"快消"也感受到文艺/好玩 → 出片位是体验峰值

---

### 2.2 溢价型

**核心机制：** `感知值 > 实际价格` → 用户觉得值得多花

命门在**买单前的感知建立**——溢价必须在用户付钱之前就已成立。

**典型业态：** 精品民宿、高端餐饮、设计酒店、独立品牌零售

**设计真杠杆：**

| 杠杆位置 | 商业逻辑 |
|---------|---------|
| 第一眼图片感（小红书/预订页） | 定价锚点在选择前已在用户脑中建立 |
| 入住 / 到达首感（开门那一刻） | 溢价感知兑现 = 决定是否后悔买单 |
| 稀缺性 / 唯一性符号 | "只有这里有"的不可替代性 |
| 高价值密度的峰值场景 | 用户记忆中最值钱的那一刻 |

**设计无效区：**
- 功能的完善程度（功能是基线，不是溢价来源）
- 过度强调材质名称（用户感知的是体验，不是材质学名）
- 面面俱到的均质精良（消解"稀缺感"）

**失败前置清单：**
1. 图片感知 ≠ 实际体验？差评爆发，溢价崩塌
2. 没有"只有这里有"的锚定点？凭什么比别人贵
3. 定价是否在目标客群的"值得"区间？超出则再好也流失

**三驱动力在溢价型的映射：**
- 盈利质量驱动力：有尊严地赚钱 → 溢价不是通过廉价竞争实现的
- 用户关系驱动力：初见（图片）→ 相处（入住体验）→ 久处（多次认可溢价）
- 交易体验驱动力：让支付行为本身变得"值得"→ 用户感到"花这个钱是对的"

---

### 2.3 复购型

**核心机制：** `第一次来 → 第二次还来 → 还带朋友来`

命门在**记忆锚点 + 关系积累**——空间必须制造"想回来"的理由。

**典型业态：** 社区餐厅、私人俱乐部、精品健身、书店咖啡、独立口腔诊所

**设计真杠杆：**

| 杠杆位置 | 商业逻辑 |
|---------|---------|
| 专属感 / 被记住感的空间语言 | "这里认识我" = 关系开始积累 |
| 每次来都有新发现的层次感 | 探索未尽 = 下次来的理由 |
| 私密 / 半私密角落 | 关系沉淀的容器 = 情感绑定 |
| 季节性 / 时间性变化设计 | 制造"这次和上次不一样"的惊喜感 |

**设计无效区：**
- 到处都是峰值，没有日常节奏（峰值过多→疲惫→不想再来）
- 完全同质化的体验（每次一样，无新发现，复购动机消失）
- 大众打卡型的传播设计（吸引陌生人，但伤害"专属感"）

**失败前置清单：**
1. 空间有没有"回头的理由"？若无，第一次很好但不会有第二次
2. 设计是否伤害了"常客特权感"？打卡人群 vs 老客，谁被优先
3. 运营是否配合？体验再好，服务断层则复购崩塌

**三驱动力在复购型的映射：**
- 盈利质量驱动力：持续性的赚钱 → 复购率是最稳定的收入底盘
- 用户关系驱动力：久处（习惯养成）→ 久别（离开仍有记忆）→ 重逢（主动回流）
- 交易体验驱动力：让"第二次"比"第一次"更有认同感 → 熟悉中的新惊喜

---

### 2.4 社群型

**核心机制：** `人与人的连接产生价值，空间是触发容器`

命门在**人在这里愿意发生关系**——碰撞触发才是设计的核心任务。

**典型业态：** 联合办公、会员制俱乐部、文化空间、创业社区、独立书店（社群属性强的）

**设计真杠杆：**

| 杠杆位置 | 商业逻辑 |
|---------|---------|
| 半开放边界（看得见但不强迫） | 自然相遇 = 社群破冰的空间条件 |
| 共同仪式感空间 | 社群认同锚点 = "我们都在这里" |
| 弹性尺度（私密→半公开→公开） | 关系深浅自选，不同阶段的人都能存在 |
| 展示墙 / 作品区 / 内容载体 | 社群内容的物理化 = 社群身份可见 |

**设计无效区：**
- 极致精美但冷漠的空间（没人敢开口说话，关系不触发）
- 完全开放无边界（缺乏安全感，关系不敢建立）
- 流量型出片位设计（吸引打卡客，破坏社群筛选）

**失败前置清单：**
1. 空间只适合独处，不触发相遇？社群永远不成型
2. 运营不配合（空间再好人不来）？设计承载不了空洞
3. 社群价值主张不清晰？谁都来 = 谁都不属于

**三驱动力在社群型的映射：**
- 盈利质量驱动力：游刃有余的赚钱 → 社群产生自传播，降低获客成本
- 用户关系驱动力：相处（消费中发现同类）→ 久处（社群归属形成）→ 重逢（主动回流参与）
- 交易体验驱动力：让"人与人的连接"成为交易的一部分 → 为圈层归属感买单

## 三、从轨：项目类型参数插件

盈利模式确定骨架后，项目类型作为参数插件，填充行业知识与典型约束。

### 类型×模式对照表

| 项目类型 | 主盈利模式（常见） | 行业关键变量 | 行业高频失败点 |
|---------|-----------------|------------|-------------|
| **街边餐饮** | 流量型为主 | 选址客流量、翻台效率、出品速度 | 选址错误，设计无效 |
| **精品民宿** | 溢价型为主，复购型为辅 | 图片感知、入住首感、在地稀缺性 | 图片 ≠ 实际体验，差评崩塌 |
| **设计酒店** | 溢价型为主 | 品牌辨识度、峰值场景密度、定价锚点 | 过于依赖设计奖项，忽视用户感知 |
| **社区咖啡** | 复购型为主，社群型为辅 | 常客维系、空间亲切度、时间弹性 | 打卡流量驱走常客 |
| **精品零售** | 溢价型为主 | 橱窗吸引力、触摸/试用触发、连带购动线 | 进店率低但不知道原因在选址还是设计 |
| **展馆/文旅** | 流量型+溢价型混合 | 门票转化、记忆峰值、二消触发、传播点 | 设计美但无传播点，口碑不扩散 |
| **联合办公** | 社群型为主，复购型为辅 | 首次参观感、日常使用舒适度、社群活跃度 | 成员只埋头干活，社群不成型 |
| **私人诊所/工作室** | 复购型为主 | 专业感知、私密感、候诊体验 | 装修过于医院化，信任感反而降低 |

### 插件使用规则
- 插件提供**行业常识与典型变量**，不覆盖主轨逻辑
- 若项目类型不在表中，系统应回到主轨盈利模式判断，不要硬套行业经验
- 同一类型项目，盈利模式不同时，行业知识也要跟着切换（如同样是咖啡馆，流量型 vs 社群型的设计逻辑完全不同）

## 四、设计决策翻译规则（系统必须执行）

每一个设计决策，系统必须能用以下格式翻译：

```
【决策】___（设计动作）
【目标】___（影响盈利链的哪个环节）
【可检验的商业效果】___（什么指标可以验证这个决策有效）
【失效条件】___（什么情况下这个决策失效或起反效果）
```

**示例（溢价型·精品民宿）：**
```
【决策】入口区设置3米高的落地玻璃+景观框景
【目标】强化"入住首感"，完成溢价感知兑现
【可检验的商业效果】入住体验评分中"第一印象"类评论中出现率
【失效条件】玻璃视线对外暴露（无私密感），或景框外无景可看
```

**禁止输出的决策格式（系统检查并拒绝）：**
- "灯光氛围温暖舒适" — 没有商业逻辑链接
- "材质选用天然石材，提升品质感" — 感知效果未绑定用户行为
- "空间整体调性偏向简约禅意" — 无法检验，无法验收

## 五、设计解决不了的问题（系统必须主动说出）

当以下情况出现时，系统必须明确告知，**不绕过，不用设计方案掩盖**：

| 问题 | 属于哪个层面 | 系统应说的话 |
|-----|------------|------------|
| 选址完全没有自然客流 | 商业选址 | "这个项目的盈利前提是地段，设计对此无效。建议先确认选址逻辑再推进空间方案。" |
| 产品定价与周边消费力严重不符 | 商业策略 | "定价逻辑决定了设计的溢价方向。当前定价 vs 周边竞品存在明显落差，建议先锁定定价策略。" |
| 运营团队不存在或无法配合 | 运营 | "复购/社群模式高度依赖运营，空间设计完成后如果运营断层，方案效果无法实现。" |
| 供应链/施工可行性存疑 | 执行 | "以下设计决策在当地供应链/工期条件下存在高风险：___，建议在方案深化前确认。" |

## 六、方法论运行顺序（系统调用逻辑）

```
Step 0 ── 破题前置
          Q1/Q2/Q3 三题判断盈利模式
          ↓
Step 1 ── 主轨锁定
          确认盈利模式（流量/溢价/复购/社群）+ 主次关系
          ↓
Step 2 ── 从轨加载
          插入项目类型参数（行业知识+典型约束）
          ↓
Step 3 ── 三驱动力铺开
          盈利质量/用户关系/交易体验 各层递进，找到本项目的关键层级
                    HEVA-H：从追问结论生成商业假设池（至少3条）
          ↓
Step 4 ── 失败前置扫描
          按主轨模式逐项检查失败清单，有风险项提前标记
                    HEVA-E/V：证据分级（E0~E4）+ 最小验证方案（阈值/窗口/责任人）
          ↓
Step 5 ── 设计杠杆排序
          列出"设计真杠杆"优先级（此处才进入空间设计讨论）
          ↓
Step 6 ── 决策翻译验证
          每个设计决策用"决策/目标/可检验效果/失效条件"格式输出
                    HEVA-A：阶段判定（PASS / PASS-WARN / FAIL）
          ↓
Step 7 ── 设计解决不了的问题声明
          主动列出本项目中设计无法解决的事项，建议前置确认
```

## 七、HEVA专项参数化（商业项目默认模板）

> 上层依赖：`HEVA验证闭环方法论-Copilot-2026-03-22.md`
> 本章提供商业项目的“即插即用”参数，不替代HEVA通用规则。

### 7.1 商业项目关键假设池（默认）

```
H1（买单前）：
    如果强化第一触点（门头/图片/首屏信息），则咨询/收藏/进店率会提升，
    最终改善首单转化。

H2（买单中）：
    如果优化关键动线与体验断点（到达、等待、支付、入住/点单），
    则流失率下降，最终改善成交率与客单。

H3（买单后）：
    如果设计可复述记忆锚点（可讲述、可推荐、可重逢），
    则复购/推荐意愿提升，最终改善LTV。
```

### 7.2 商业项目证据等级门槛

| 决策类型 | 最低证据等级 | 备注 |
|---------|--------------|------|
| A类不可逆决策（结构/核心定位） | E2 | 建议E3后冻结 |
| 高投入杠杆位决策 | E2 | 需给出失败阈值 |
| 风险项（P1/P4命中）对应决策 | E3 | 必须有回滚方案 |
| B类可逆决策 | E1 | 可先做后调 |

### 7.3 民宿专项KPI树（默认口径）

```
终局指标（L3）：
    RevPAR / 入住率 / 复购率 / 推荐率

中层指标（L2）：
    首单转化率（咨询→预订）
    入住首感正向评价占比
    价格“值得”相关评价词频
    复购意愿（愿意再来）

前置信号（L1）：
    平台收藏率/点击率
    到达后15分钟负面反馈率
    夜间噪音相关反馈率
    “会推荐给朋友”当场回答比例
```

### 7.4 民宿专项阈值建议（可按项目修订）

| 指标 | PASS | PASS-WARN | FAIL |
|------|------|-----------|------|
| 咨询→预订转化率 | ≥ 12% | 8%~12% | < 8% |
| 首感正向评价占比 | ≥ 70% | 55%~70% | < 55% |
| 噪音负面反馈率 | ≤ 8% | 8%~15% | > 15% |
| 复购/推荐意愿 | ≥ 60% | 45%~60% | < 45% |

> 说明：阈值为方法论默认值，具体项目可按地段、价位、客群分层校准。

### 7.5 失败后的动作协议（商业项目）

```
若买单前指标FAIL：
    优先回到“比较胜出逻辑”，先修正触达与锚定，不先重做空间细节。

若买单中指标FAIL：
    优先修复体验断点（等待/动线/支付/入住首感），
    暂停新增“锦上花”设计动作。

若买单后指标FAIL：
    优先补“可复述记忆锚点”与“重逢触发机制”，
```
