## 〇、框架前言：设计行业的系统性盲点

马斯洛需求层次理论揭示了人类需求的垂直结构。但在空间设计行业，这个结构被严重错位使用：

```
行业过度集中的层级：第三层（审美认同）
行业系统性遗忘的层级：第一层（基础安全）+ 第五层（意义超越）
```

结果是：
- **底层缺失**：隔音差、私密性不足、安全感缺失——用户睡不好、坐不住、无法放松。他们说不清楚为什么，但就是觉得"不对"。打了低分，也说不出原因。
- **中层拥挤**：全行业都在做"美学认同"这一层，内卷严重，差异化极难，审美疲劳加速。
- **顶层空白**：意义感、自我超越、与更大事物的连接——这是现代城市人最稀缺的体验，也是溢价最强、复购最深、传播最广的层级。**几乎没有人认真设计过这一层。**

**本框架的核心使命：**
让系统能识别一个设计方案在哪几层有覆盖、哪几层存在盲区，并据此调整资源分配。

## 一、五层需求框架（设计行业版）

### 层级一 — 基础安全层
**核心命题：** 这里让我感到安全、私密、不被打扰

```
覆盖的需求：
  生理安全：温度适宜/采光充足/通风良好/噪音受控
  人身安全：门锁可信/出入口清晰/紧急出口可见
  隐私安全：不被陌生人看到/不被偷听/行为不被监视
  睡眠安全：隔音达标/遮光可控/床的支撑感
  如厕安全：私密、干净、功能齐全（被严重低估的需求）

设计失败信号：
  × 用户睡不好，说不清楚为什么（通常是隔音/温度/光线）
  × 进门就下意识皱眉或四处张望（安全感缺失）
  × 评论里出现"隐私感差"/"能听见隔壁"/"有点担心"
  × 用户在空间里无法放松，持续保持社交状态

致命规律：
  这一层没做好，上面所有层级全部失效。
  再美的星空，在隔音差的民宿里，用户只能听见隔壁的鼾声。
  用户会记得鼾声，不会记得星空。

常见设计陷阱：
  → 用"氛围感"掩盖隔音缺陷
  → 用"开放感"牺牲私密性
  → 用"工业风"合理化不够温暖的室温
  → 卫生间被设计压缩，功能变差
```

---

### 层级二 — 舒适功能层
**核心命题：** 这里好用，我的身体和行为在这里是顺畅的

```
覆盖的需求：
  身体舒适：座椅/床/地面对身体的支撑
  行为顺畅：动线自然/收纳充足/插座在对的位置
  认知顺畅：开关在找得到的地方/空间逻辑清晰/不需要摸索
  感官舒适：灯光色温/气味/材质手感

设计失败信号：
  × 用户住了一晚找不到插座或开关
  × 行李没有地方放（常见于强调"极简"的空间）
  × 灯光只有一种模式，无法调节（餐饮常见：只有打卡模式，无法日常社交）
  × 用户需要学习才能使用空间（复杂度高于功能需求）

致命规律：
  用户不会主动称赞这一层（"功能好"不是值得发朋友圈的理由）
  但缺失会被投诉，且是差评的高频来源。
  "好看但不好用"是这层失败的标准句式。

常见设计陷阱：
  → 为了美观压缩功能收纳（极简的代价是用户把东西堆在地上）
  → 灯光方案只考虑拍照效果，不考虑实际使用时的光照需求
  → 动线设计为了视觉效果而非行为逻辑
```

---

### 层级三 — 审美认同层
**核心命题：** 这里很美，我认可这种美，我愿意和它产生关联

```
覆盖的需求：
  视觉愉悦：空间美得让人想多看
  风格认同：这种美是"我的审美"，不是"我不懂的审美"
  拍照价值：我愿意把它分享给朋友
  品味背书：来这里，体现了我有品味

设计失败信号：
  × 拍完照离开，再无留恋（峰值仅在视觉层，没有深层连接）
  × 用户说"很漂亮但不知道风格是什么"（美感丰富但没有立场）
  × "哇这很像X品牌/X民宿"（审美认同但无差异化，属于P6滥用区）
  × 用户感到"看不懂"（审美层超出了目标用户的认知范围）

行业现状（系统必须认知）：
  这是整个设计行业竞争最激烈的层级。
  全频谱扫描P6（滥用检查）的主要战场就在这里。
  差异化极难，审美疲劳加速，模仿周期越来越短。
  在这层做到顶，只能暂时领先，无法持续领先。

常见设计陷阱：
  → 把全部资源投入审美层，忽略一二层的基础
  → 追求"最高水准的美"而不是"目标用户认可的美"
  → 把审美当成终点，而不是通往更深层需求的入口
```

---

### 层级四 — 社交身份层
**核心命题：** 来这里，让我成为/表达了"我是什么样的人"

```
覆盖的需求：
  身份表达：这次消费说明"我是有品味/有眼光/有生活的人"
  社交资本：在朋友/伴侣/同事面前，来过这里是一种加分
  圈层归属："来这里的人和我是同类"
  带人来的理由："带你来这里"本身就是一种礼物或表达

设计失败信号：
  × 来了，但不想发朋友圈（空间没有成为身份符号）
  × 来了，拍了，发了，但朋友问的不是"在哪里"而是"那是什么"（符号不清晰）
  × 带朋友来，朋友的反应平淡（身份背书失效）
  × 空间服务的是"所有人"，no one feels special（圈层无法识别）

商业价值：
  这层是溢价的主要来源之一。
  用户为"成为什么样的人"付的钱，比为"得到什么功能"付的钱多得多。
  身份层有效的项目，口碑传播中"带人来"的比例高。

常见设计陷阱：
  → 试图服务所有人的身份需求，结果谁都不认同
  → 把"有品味的标志"做得太高端，目标用户跨不过去
  → 忽视"熟客的身份感"——第一次来有面子，第二次呢？
```

---

### 层级五 — 意义超越层
**核心命题：** 在这里，我短暂地感到自己是完整的、渺小的、有意义的

```
覆盖的需求：
  自我超越：短暂脱离日常身份和焦虑，感到"更大的自己"
  存在感知：感到活着是有重量的，而不是在流水线上滑动
  与自然/时间/世界的连接：渺小感带来的平静，不是恐惧
  沉默的意义：不需要做什么，不需要说什么，就已经够了

民宿场景展开（"仰望星空的背后是..."）：
  不是星空本身——星空只是触发器
  是那一刻：
    城市里的焦虑暂时消失了
    手机放下了，没有信息需要回
    感到自己很渺小，但这种渺小让人松了一口气
    忽然想起来，自己其实还活着，而且活得挺好
    和身边的人之间，不需要说话，沉默也是温暖的

  这是现代城市人极度稀缺的体验。
  城市生活的密度和速度，让这种"存在感"几乎消失。
  民宿的地理位置提供了场景，但设计决定了这种感受能不能真正发生。

设计失败信号：
  × 空间里没有任何让人"停下来"的时刻
  × 每个角落都在提示"你来拍照/来消费/来社交"，没有沉默的空间
  × 声光过度设计，没有留白，感官一直处于被刺激状态
  × 用户离开后只能说"很好看"，说不出"有什么感受"

差异化价值（系统必须知道）：
  做到这层的项目，具有不可复制性。
  因为这层的体验无法被模仿——可以复制梯田、可以复制原木、
  但无法复制"那个让人忽然感到平静"的时刻。
  口碑传播里，这层产生的描述最动人，也最容易感染潜在用户。
  溢价最强：人们愿意为"那种感觉"付出超出理性的价格。

如何设计这一层（具体动作）：
  → 至少有一个"不需要做任何事"的空间（无功能区）
  → 声音的留白：有些时刻不需要音乐，需要自然声或沉默
  → 视线的出口：给眼睛一个"可以望远"的去处
  → 时间感的重建：让人感知到白天/黑夜/季节的变化（而不是恒温恒光）
  → 身体的着地：让人感到脚踏实地、有重量、在场（而不是悬浮的网红感）
  → 独处容器：至少有一个角落，一个人坐着不尴尬
```

## 一·五、双轴映射：刚需 / 享受型 / 精神型 × 实用性 / 情绪价值

你提出的维度非常关键，它与五层需求框架不是替代关系，而是**投影关系**：

- 五层框架回答：需求在**哪一层**
- 双轴框架回答：需求属于**哪一类价值组合**

### 映射总表（系统默认）

| 类型 | 主导价值 | 对应层级（主） | 对应层级（辅） | 设计投入原则 |
|------|----------|----------------|----------------|--------------|
| **刚需型** | 实用性为主，情绪价值为辅 | 层级一 基础安全层 | 层级二 舒适功能层 | 先补缺口再谈审美；不达标不得上卷 |
| **享受型** | 实用性 + 情绪价值并重 | 层级三 审美认同层 | 层级二/四 | 审美必须绑定使用场景，避免“只好看” |
| **精神型** | 情绪价值为主，实用性为底 | 层级五 意义超越层 | 层级四 社交身份层 | 必须建立“可停留、可沉默、可回想”的节点 |

### 民宿场景的典型映射

```
刚需型（底线）：
  安全 / 隐私 / 隔音 / 睡眠 / 如厕舒适
  → 这是“住得下去”的条件，不是“住得惊艳”的条件

享受型（体验）：
  视觉审美 / 触感材质 / 气味与灯光 / 拍照与社交分享
  → 这是“愿意多待一会儿”的条件

精神型（超越）：
  仰望星空背后的“存在感恢复”
  从信息噪声中抽离，重新感到自己在场
  与自然/时间/亲密关系发生安静连接
  → 这是“愿意记住并再回来”的条件
```

### 执行判定规则（系统强制）

```
规则1：先刚需，后享受，再精神
  刚需缺口未闭合时，享受型与精神型投入按风险项处理

规则2：双轴必须可检验
  刚需型用客诉/复住基础体验指标验证
  享受型用停留时长/分享率/即时满意度验证
  精神型用复购意愿/深度评价（非打卡式）/回想触发率验证

规则3：避免“伪精神化”
  只有审美符号（星空灯、禅意摆件）但没有真实安静体验节点
  判定为“伪精神型”，按层级三处理，不得计入层级五成果
```

### 一句话落地模板（用于任务书）

```
本项目需求结构：
  刚需型（__%）/ 享受型（__%）/ 精神型（__%）
资源分配建议：
  层级一二（__%）/ 层级三四（__%）/ 层级五（__%）
关键风险：
  若___（刚需缺口）未关闭，则___（享受/精神投入）将失效。
```

## 二、层级不可跳跃定律

**这是整个框架最重要的规则，系统必须强制执行。**

```
层级一有缺口 → 所有上层投入价值打折，甚至归零
层级二有缺口 → 用户记住不便，审美体验被行为摩擦侵蚀
层级三有缺口 → 没有吸引力，用户进不来（但有了一二层，用户至少不会差评）
层级四有缺口 → 可以很好，但缺乏溢价空间和传播动力
层级五有缺口 → 可以优秀，但无法不可替代
```

### 资源分配原则（基于层级）

```
错误做法（业内常见）：
  把60%资源投入层级三（审美）
  用剩余资源勉强保障层级一二
  层级四五靠运气

正确做法：
  层级一：必须达标（不是最漂亮，但必须没有明显缺陷）
           → 这是底线，不是特色，不需要过度投入
  层级二：必须顺畅（用户行为无明显摩擦）
           → 性价比投入，不需要豪华，需要细心
  层级三：足够好（目标用户认可的美，不需要最高水准）
           → 中等投入，聚焦目标用户审美，不追求大众认可
  层级四：重点突破（身份符号清晰，圈层感强）
           → 高价值投入，是溢价的来源
  层级五：至少有一个时刻（不需要全空间，需要一个精心设计的节点）
           → 最高质量的单点投入，是不可替代性的来源
```

## 三、层级诊断工具（系统使用）

### 快速诊断问题组

系统针对任何项目，可以用以下问题快速定位需求层级现状：

```
层级一诊断：
  D1-1 用户在这里能睡好觉吗？（隔音/温度/遮光）
  D1-2 用户在这里感到私密吗？（不被看、不被听、不被打扰）
  D1-3 如果用户有一个隐私行为需求，这里能满足吗？

层级二诊断：
  D2-1 用户的日常行为（充电/收纳/如厕/照明）是否顺畅？
  D2-2 空间有没有需要"学习才能使用"的地方？
  D2-3 功能是否被审美设计牺牲了？

层级三诊断：
  D3-1 目标用户会认可这种美吗？（不是所有人，是目标用户）
  D3-2 这种美是否有立场？还是什么风格都想要？
  D3-3 这种美是否有差异化？还是同类竞品都长这样？

层级四诊断：
  D4-1 来这里的人，会在朋友面前说吗？用什么理由？
  D4-2 这个空间服务的是哪个圈层的身份表达？
  D4-3 老客和新客，这里给他们的身份感有区别吗？

层级五诊断：
  D5-1 这里有没有一个让人"停下来，什么都不做"的时刻？
  D5-2 用户离开后，能不能说出一个"说不清楚但很难忘"的感受？
  D5-3 这里设计过"沉默"吗？（不是没有设计，而是主动设计了沉默）
```

## 四、各项目类型的层级盲区速查

| 项目类型 | 高频忽略的层级 | 高频过度投入的层级 | 最大机会层级 |
|---------|-------------|-----------------|------------|
| **精品民宿** | 层级一（隔音/私密）+ 层级五（超越感） | 层级三（拍照审美） | 层级五 |
| **网红餐饮** | 层级二（翻台效率/动线功能） | 层级三 + 层级四（打卡/身份） | 层级四（圈层归属） |
| **设计酒店** | 层级一（睡眠品质）+ 层级二（旅行功能需求） | 层级三（设计奖项感）| 层级四 + 层级五 |
| **社区咖啡** | 层级四（常客身份感 vs 新客需求）| 层级三 | 层级五（日常意义感） |
| **联合办公** | 层级一（隔音/专注感）+ 层级二（工作功能） | 层级三 + 层级四（社群氛围） | 层级四（归属感） |
| **零售空间** | 层级二（选购行为顺畅度）| 层级三（视觉陈列美感） | 层级四（购买=身份表达） |
| **私宅** | 层级一（被业主忽略的真实居住需求）| 层级三（风格实现） | 层级五（家的归属意义） |

## 五、第五层深度指南：如何设计"意义超越"时刻

这层是整个框架中设计行业覆盖最少、价值最高的区域。独立展开。

### 什么是"意义超越"时刻

```
不是宏大的仪式感，是一个人的、安静的、无法被分享的瞬间。

它通常发生在：
  → 一个人独处的时候（不是在表演给别人看）
  → 身体真正放松下来的时候（不是表演放松）
  → 感官接触到了某个"真实的东西"（自然/时间/重量/温度）
  → 脑子里的噪音暂时停下来的时候

民宿版本：
  → 清晨，还没有任何人说话，一个人坐在窗边
  → 仰望星空，感到城市的焦虑在宇宙尺度下显得可笑
  → 下雨，听雨，什么也不想
  → 晚上，蜡烛，伴侣，不需要说话
  → 独自行走在一条小路上，感到脚踩着地，自己有重量
```

### 触发条件（设计可以创造）

```
① 感官减法——不是加更多，是减少刺激
  → 某些时刻，关掉音乐，关掉多余的光，让空间安静下来
  → 材质的触感（手摸到的木头/石头/陶土），比视觉更直接触达存在感

② 时间感的设计
  → 让用户感知到时间的流逝（日出/日落/星空/晨雾/季节变化）
  → 现代建筑的恒温恒光是时间感的杀手——有意引入"时间的变化"

③ 视线的出口
  → 在对的地方开一扇窗，给眼睛一个"可以望去"的地方
  → 不是为了景观，是为了让视线有地方去，让思绪松开

④ 身体的着地
  → 让人感到有重量、在场（而不是"悬浮的网红感"）
  → 厚实的地毯、低矮的坐具、石头的台阶——都在告诉身体"你在这里"

⑤ 独处的合法性
  → 至少有一个角落，一个人坐着不尴尬（周围的设计不逼迫你"应该和别人互动"）
  → 这在民宿里尤为重要：很多空间的设计前提是"你不会一个人在这里"
```

### 验收方式

```
不能用"有多美"来验收这层，用以下方式验收：

→ 在这个空间独处15分钟，能感到什么？
→ 离开之后，有没有一个时刻会忽然想起来？
→ 用户在描述这个地方时，有没有说出"说不清楚的感觉"？
  （"说不清楚"恰恰是第五层成功的标志——因为第五层的体验超出了语言范围）
```
